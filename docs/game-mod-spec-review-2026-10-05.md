## 3. 배포·백업의 현재 범위

기존 수동 배포는 ANPC Lua/redscript 및 자체 DLL 설치/교체였다. 변경 전 백업·전후 SHA-256은 남겼으나 임시 폴더가 유일한 복구본인 경우가 있었다. 이번에 기존 백업 36개 폴더·204개 파일·211856976바이트와 배포 JSON을 Git 제외 config.local.backups 아래로 복사하고 파일별 해시를 확인했다. 세이브는 이전에 확보한 스냅샷이며 실행 중 게임의 새 저장 캡처를 했다는 뜻이 아니다.

현재 CI는 DLL 하나를 산출한다. 이번에 DIST-01~06을 기준으로 [개발 패키지 생성기](../scripts/build-game-package.ps1)와 [출시 상태](../game/package-profile.json)를 추가했다. 실제 설치된 자체 DLL과 현재 소스로 개발 ZIP을 만들었고 게임 설치 파일 18개·문서/고지·목록을 합쳐 25개 항목을 검증했다. 공개 채널은 미승인 상태에서 거부한다. 사용자 설정 보존·실패 복원·제거를 포함한 제품 설치 수용은 여전히 미완이며 SR-12/13을 해결한 것으로 표시하지 않는다.

개발 패키지 검사는 ZIP 중앙 디렉터리를 독립적으로 읽어 내용/크기/해시·설치 경로·새 정체성 소스 포함·제외 파일·동일 산출물·공개 채널 거부·잘못된 DLL 거부를 확인한다. 검사 fixture DLL은 실행하지 않으며 실제 게임 빌드 검증을 뜻하지 않는다.

## 4. 문서 수정과 다음 작업

UF-63/SR-15: 사용자는 조니 등 인물별 비속어와 군중의 자발적 성인 농담·세계관에 맞는 태도를 요청했다. 현재 speech_rules의 유머/욕설 제한이 12명 모두 거의 같고, 군중은 한 말투 후보만 사용하며 세부 speech_rules를 게임 인물 데이터로 옮기지 않는다. 인물별 작성 강도·군중 말투 유지·일상 가치 표현·성인 대상 조건으로 프롬프트/전달 경로를 조정했다. 선택한 로컬 speech_rules만 생성 지침으로 투영하고 플레이어/게임 표시 문자열은 지침에 넣지 않는다. 조니의 강한 욕설·절제된 미스티·거친 군중의 비노골적 말장난·성인 조건 미확인의 제한을 실제 API 샘플에서 확인했다. 전체 인물 문체와 실게임 검증은 미완이다. 성격 점수·오리지널 관계·인지 조건·콘텐츠 승인 상태는 변경하지 않는다.

UF-62/SR-14: 사용자가 대화 입력 중 Tab의 캐릭터/인벤토리 메뉴가 열리지 않는 문제를 보고했다. Node 106/106, Lua/실제 설치 기준 CLI 컴파일은 통과했으며 실제 게임에서 Tab과 메뉴 복귀를 확인한 결과는 아직 없다. 기존 일반 메뉴 보호의 명시적 예외이며 SR-01의 나머지 안전 조건을 완료한 것으로 표시하지 않는다.

README/runtime의 ‘게임 어댑터 구현·컴파일·실게임 검증 전부 미수행’, 구현 계획의 ‘G0/G1만 소스 있음’은 현재 기록과 달랐다. 최신 검증 문서로 안내를 바꾸고 역사 기록은 보존한다. Native 경로는 실제 red4ext/plugins/ANPC에 맞춘다.

## AMM 동작 연동 변경 범위

UF-64/65, UF-28/30/44~49/60/62 및 DIST-07/10을 적용한다. 대사와 최대 한 행동을 한 요청에서 생성한다. AMM 메타데이터와 자원의 교집합만 제공하고, 원본/타 모드 제어는 점유하지 않는다. 실행 직전 조건 변경 시 행동만 거부하고 수용된 대사는 유지한다. 세션·세계·메뉴 취소 및 소환 중 취소를 자동 검사하고 redscript 컴파일·웹 결과 표시·실게임 재생을 각각 기록한다. 외부 자원은 ANPC 배포 ZIP에 포함하지 않는다. AMM 2.12.5 정식 패키지와 ArchiveXL 1.27.3을 확보해 필요한 파일을 설치했고 원본 ZIP/설치 해시를 확인했다. 사용자가 실게임 검증을 제외했으므로 실제 모션 재생·제어 복귀는 미검증으로 유지한다.
## UF-66 선택·관계·메인 진행과 비밀 인지 매핑

현재 웹의 진행/관계/렐릭 설정은 실제 게임 binding 전체와 연결되어 있지 않다. 본편/확장 게임 파일을 읽기 전용으로 추출해 선택지 식별자와 뒤따르는 fact 기록·후속 검사·일지 상태 변경을 연결한다. 인물 12명의 인지와 관계, 82개 퀘스트 후보의 진행/완료/실패를 조사 범위로 삼는다. 파일 해시·패치 버전·노드/옵션·설정/검사 값을 보관하고 단순 문자열 발견을 의미 검증으로 승격하지 않는다. 저장되지 않은 선택·미기록 0·상충 상태는 unknown이며 원본 상태를 수정하지 않는다. 사용자가 제외한 실게임 검증은 수행하지 않고 정적 분석과 런타임 연결을 별도 표시한다.
### UF-66 주디·팬앰·조니 우선 연결

우선 개발 연결은 24개 실제 일지 경로와 13개 쓰기 근거가 있는 fact를 읽는다. Context의 CET 내부 스냅샷에만 원시 값을 보관하고, 주디/팬앰/조니의 현재 관계·공개된 사건·필터된 지식으로 투영한다. 기존 공통 필드와 canon_context를 사용하며 공통 포트 전환 완료로 표시하지 않는다. 친구/연인/거절·공개/비공개의 0은 관련 퀘스트 완료/공개 완료가 확인된 분기에서만 사용한다. 단절·실패·결말·진행 불명·상충은 차단하거나 unknown으로 유지한다. 대기 응답은 해당 인물의 진행/인지가 변경되면 폐기하고 자동 재호출하지 않는다. 일부 중간 창의 authored 관계 카드 부족은 unknown으로 남긴다. 게임 상태 쓰기와 실게임 검증은 수행하지 않는다.
