# ANPC 전체 제품 명세

규격 버전: 0.4 (2026-10-01). 이 문서는 제품 요구사항과 범위를 정의한다. 세부 계약은 아래 분야별 문서를 따른다. 구현 가능성 분석과 시험 절차는 제품 명세에 포함하지 않는다.

## 1. 제품 목적

ANPC는 플레이어가 사이버펑크 2077의 NPC에게 채팅으로 먼저 말을 걸면 인물·세계관·현재 상황에 맞는 대사와 행동으로 반응하는 모드다. 길거리 군중과 지원 커뮤니티 인물을 대상으로 한다. 핵심 품질은 인물별 정체성, 지식 경계, 실제 게임 상황과 대화의 연속성이다.

## 2. 요구사항

| ID | 요구 |
| --- | --- |
| P01 | 플레이어가 단일 NPC를 선택해 텍스트 대화를 시작·취소·종료할 수 있어야 한다. |
| P02 | 커뮤니티는 고정된 원작 정체성을 사용하고 군중은 승인된 원형·배경과 생성 성격을 동일 인스턴스에서 유지해야 한다. 신규 핵심 성격은 Big Five 규격, 기존 자료의 전환 경계는 콘텐츠 규격을 따른다. |
| P03 | 장비·평판·진척도·지역은 해당 인물이 관찰하거나 알 수 있는 범위에서 반영해야 한다. |
| P04 | NPC는 답변·후속 질문·거절·경고·종료 의사를 표현할 수 있어야 한다. |
| P05 | 행동은 현재 허용 목록의 등록된 동작만 실행해야 한다. |
| P06 | 유효한 같은 NPC에게 재접촉하면 최근 대화와 특성이 이어져야 한다. |
| P07 | 게임 원작 대화·퀘스트·전투 제어가 ANPC보다 우선해야 한다. |
| P08 | 플레이어 개인 API 키를 사용하고 제작자 운영 서버를 두지 않아야 한다. |
| P09 | AI 지연·장애·늦은 응답이 게임 프레임을 막거나 잘못된 대상에게 적용되어서는 안 된다. |
| P10 | 키·불필요한 개인정보·대화 원문은 기본 로그에 남기지 않아야 한다. |
| P11 | 기억 기능은 단기 문맥과 장기 기록을 분리하고 관련 기억만 조회해야 한다. 정리는 대사 생성과 별도 비동기 작업으로 수행하며 정체성·승인 지식을 변경해서는 안 된다. |
| P12 | 고유 인물의 기존 선택지 아래 AI 대화 진입 선택지를 제공하고 군중은 짧은 기본 반응 뒤 같은 진입 선택지를 제공해야 한다. 원작 제어와 안전하게 전환해야 한다. |
| P13 | 현재 표시 복장의 이름·외형 텍스트와 같은 NPC의 이전 관찰 기억을 이용해 인물·원작 관계에 맞는 복장 대화를 제공해야 한다. |
| P14 | AI 대화는 원작 퀘스트·관계·친밀도를 변경하지 않으며 진행도별 맥락을 사용해야 한다. 대화 이력으로 별도 누적 관계를 만들지 않는다. |
| P15 | 처음 만난 시민도 승인된 평판 규칙에 따라 V의 이름·공개 행적을 알아볼 수 있어야 한다. 비밀 인지 권한은 별도로 유지한다. |
| P16 | 원작과 충돌하지 않는 사소한 일상 창작을 허용하되 원작 사실·게임 관찰·직접 전문 경험과 구분해야 한다. |
| P17 | NPC 대사는 자막으로 표시하고 게임은 계속 진행해야 한다. 위험·원작 제어 발생 시 대화와 ANPC 제어를 정리해야 한다. |
| P18 | 초기 추가 행동은 선택만 하고 후속에 기존 게임·모드 연동으로 대화에 맞게 실행해야 한다. 기본 멈춤·시선·해제는 실제 실행한다. |

## 3. 사용자 흐름

대상 선택 → 원작 대화 또는 군중의 짧은 기본 반응 → 추가 선택지 선택 → 원작 제어 반환·허용 판정 → 채팅 열기·기본 멈춤/시선 → 입력 전송 → 진행도·인물·지식·관찰·기억 조립 → AI 요청 → 표시 전 재검사 → 대사 자막·행동 선택 결과 표시 → 지원 프로필에 따른 실제 행동 또는 추가 입력/종료다. 진입 절차는 [NPC 식별 규격](npc-identity-specification.md#21-ai-대화-진입과-원작-제어-전환), 자막은 [통신 규격](runtime-specification.md#7-대사-자막과-게임-진행)을 따른다.

UI는 대상 이름, 대화 기록, 입력창, 응답 대기, 취소·종료와 오류 안내를 제공한다. 입력창이 포커스를 가지면 게임 조작 키의 중복 처리를 차단한다. 서비스 오류 안내와 인물의 대사는 구분한다.

## 5. 단계별 기능 경계

NPC 음성 출력은 승인된 대사를 자막과 함께 재생해야 한다. 음성 실패에도 대사는 유지하고 세션 종료 시 음성을 중단해야 한다. 플레이어 음성 입력은 포함하지 않는다.

단기·장기 조회·로컬 정리와 안정적으로 식별되는 커뮤니티의 저장별 기억·로드 복원은 첫 게임판 목표이며 [NPC 기억 규격](memory-specification.md)을 따른다. 유료 기억 요약과 로컬 모델은 후속 선택 기능이다. 행동 확장은 기존 자산과 모드별 어댑터를 통해 단계적으로 실제 실행하며 [행동 연동 계약](npc-action-scope.md#10-기존-게임모드-행동-연동)을 따른다. 신규 모션 제작은 필수 작업이 아니다. 원작 음성의 복제 방식과 특정 모델·제공자를 이 문서에서 고정하지 않는다.

## 6. 제외 범위

제작자 공용 API 키·중계 서버, 원작 퀘스트 대체·임의 진행 변경, 모든 NPC의 일괄 지원, 군중 재생성 이후 개인 기억 승계, 임의 코드·애니메이션 생성, 플레이어 음성 입력은 제외한다. 다중 NPC 자율 대화와 입력 없는 상시 AI 시뮬레이션도 초기 범위에서 제외한다.
