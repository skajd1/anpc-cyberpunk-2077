# ANPC 전체 제품 명세

규격 버전: 0.5 (2026-10-07). 제품 범위/요구사항. 세부 타입/정책은 분야별 기준 참조. 구현/시험은 [개발·검증 계획](development-validation.md).

## 1. 제품 목적

플레이어가 군중/지원 커뮤니티 NPC에게 텍스트로 먼저 대화하고 인물·세계관·현재 상황에 맞는 대사/행동을 받는다.

| P01 | 단일 NPC 선택·텍스트 시작/취소/종료 |
| P02 | 커뮤니티 오리지널 고정, 군중 승인 원형/배경/성격의 동일 인스턴스 유지. 신규 핵심 성격은 Big Five |

## 3. 사용자 흐름

대상 → 오리지널/군중 반응 → 추가 선택지 → 제어 반환/허용 검사 → 채팅/기본 제어 → 입력 → 맥락 조립/생성 → 현재 조건 검사 → 자막·음성/선택 결과 → 지원 행동 또는 추가 입력/종료.

UI: 이름·기록·입력·대기·취소/종료·오류. 입력 포커스의 게임 키 중복 차단. 서비스 오류/NPC 대사 분리.

플레이어 행동별 조건·반응·관찰 결과는 [게임 기능 명세](gameplay-functional-specification.md)의 UF-01~63을 기준으로 한다. 설치/업데이트/백업/복원/제거는 [배포 규격](mod-distribution-specification.md)을 따른다. 현재 코드와의 차이는 [개발·검증 계획](development-validation.md#2-출시-전-남은-결함)에 기록한다.

## 5. 단계별 기능 경계

단계는 [초기 명세](initial-design.md). 첫 게임판: 근거리 군중/저장 연동 커뮤니티 기억·조회/로컬 정리·일본어 NPC 음성. 후속: 지원 기존 자산/모드 행동·선택 유료 요약/로컬 모델.

NPC 음성은 첫 게임판 기본 기능이다. 주요 인물 음성으로 파인튜닝한 단일 로컬 TTS 모델이 인물·감정별 원작 참조 음성을 따라 사용자 PC에서 합성한다. 모델은 배포 권리 확인 후 배포하고 인물을 더하며 업데이트한다. 참조·학습·생성 음성은 배포하지 않는다. 실패는 대사 유지, 종료는 재생 중단. 신규 모션 제작 필수 없음.

플레이어 음성 인식은 선택 후속 확장이다. [음성 인식 규격](speech-recognition-specification.md)에 따라 확정 전사문만 기존 텍스트 대화 경로로 전달한다. NPC 음성 출력과 독립적으로 설치/활성화한다.

## 6. 제외 범위

제작자 공용 키/서버·오리지널 퀘스트 대체/임의 진행·전체 NPC 일괄 지원·재생성 군중 승계·임의 코드/모션 생성·첫 게임판 플레이어 음성·초기 다중 NPC 자율/상시 AI 제외.
