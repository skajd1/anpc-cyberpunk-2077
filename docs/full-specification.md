# ANPC 전체 제품 명세

규격 버전: 0.4 (2026-10-01). 제품 범위/요구사항. 세부 타입/정책은 분야별 기준 참조. 구현/시험은 [개발·검증 계획](development-validation.md).

## 1. 제품 목적

플레이어가 군중/지원 커뮤니티 NPC에게 텍스트로 먼저 대화하고 인물·세계관·현재 상황에 맞는 대사/행동을 받는다.

## 2. 요구사항

| ID | 요구 |
| --- | --- |
| P01 | 단일 NPC 선택·텍스트 시작/취소/종료 |
| P02 | 커뮤니티 원작 고정, 군중 승인 원형/배경/성격의 동일 인스턴스 유지. 신규 핵심 성격은 Big Five |
| P03 | 장비·평판·진행·지역은 개인 관찰/인지 범위 내 반영 |
| P04 | 답변·질문·거절·경고·종료 의사 |
| P05 | 현재 허용 등록 행동만 실행 |
| P06 | 같은 유효 NPC 재접촉 시 특성/최근 기억 유지 |
| P07 | 원작 대화·퀘스트·전투 제어 우선 |
| P08 | 개인 API 키, 제작자 서버 없음 |
| P09 | 비동기 요청. 게임 프레임 차단/늦은 응답 오적용 금지 |
| P10 | 키·불필요 개인정보·원문 기본 로그 제외 |
| P11 | 현재 세션 발화·세션당 한 줄 요약. 승인 정체성/지식 수정 금지 |
| P12 | 커뮤니티 기존 선택지/군중 기본 반응 뒤 추가 진입 선택지. 안전 제어 전환 |
| P13 | 현재 표시 복장을 인물·원작 관계에 맞게 활용. 관찰 이력 의무 보존 없음 |
| P14 | AI 퀘스트/관계 변경 및 별도 누적 관계 금지. 현재 원작 진행 맥락 적용 |
| P15 | 승인 평판으로 첫 시민의 이름/공개 행적 인지. 비밀은 별도 권한 |
| P16 | 사소한 일상 창작은 원작/관찰/전문 경험과 분리 |
| P17 | NPC 자막·게임 진행 유지. 위험/원작 제어 시 정리 |
| P18 | 기본 멈춤/시선/해제 실행. 추가 행동은 초기 선택, 후속 지원 연동 실행 |

## 3. 사용자 흐름

대상 → 원작/군중 반응 → 추가 선택지 → 제어 반환/허용 검사 → 채팅/기본 제어 → 입력 → 맥락 조립/생성 → 현재 조건 검사 → 자막/선택 결과 → 지원 행동 또는 추가 입력/종료.

UI: 이름·기록·입력·대기·취소/종료·오류. 입력 포커스의 게임 키 중복 차단. 서비스 오류/NPC 대사 분리.

## 5. 단계별 기능 경계

단계는 [초기 명세](initial-design.md). 첫 게임판: 근거리 군중/저장 연동 커뮤니티 기억·조회/로컬 정리. 후속: 지원 기존 자산/모드 행동·NPC 음성·선택 유료 요약/로컬 모델.

음성은 확정 대사/자막 연결, 실패는 대사 유지, 종료는 재생 중단. 특정 제공자/음성 복제/신규 모션 제작 필수 없음.

플레이어 음성 인식은 선택 후속 확장이다. [음성 인식 규격](speech-recognition-specification.md)에 따라 확정 전사문만 기존 텍스트 대화 경로로 전달한다. NPC 음성 출력과 독립적으로 설치/활성화한다.

## 6. 제외 범위

제작자 공용 키/서버·원작 퀘스트 대체/임의 진행·전체 NPC 일괄 지원·재생성 군중 승계·임의 코드/모션 생성·첫 게임판 플레이어 음성·초기 다중 NPC 자율/상시 AI 제외.
