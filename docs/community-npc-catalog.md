# 대표 커뮤니티 NPC 12명 및 세계관 자료 조사

작성일: 2026-09-30. 보강: 2026-10-03. 선정한 인물 12명의 기본 배경·정체성 방향·전문 지식·대화 제한을 조사하고 콘텐츠 파일로 정리했다. 원작 사실과 작성 해석은 별도 필드로 저장했다. 콘텐츠의 기준 데이터는 [자료 목록](../content/cyberpunk2077/manifest.json), 배분 기준은 [NPC 지식 규격](npc-knowledge-specification.md)이다.

## 1. 정리한 범위

- 인물 카드 12개: 배경, 신념·욕구·두려움·금기, 판단 규칙, 문체 방향, 대체 대사, 단계, 지식·예시 참조.
- 세계관·인물 사실 217개: 공통 핵심 상식 35개와 선별 세부 지식·개인 경험·원작 관계 사건.
- 인물별 지식 후보 881개: 같은 사실을 인물별 인지·공개·해석 조건으로 참조.
- 새 상황의 대사 예시 28개. 원작 대사 인용이나 실제 모델 응답이 아닌 검수 전 작성 예시.
- 군중 지식 묶음 후보 13개: 공통, 지역 7개, 직업 4개, 선택 관심 목록.

12명 전체를 정리한 개발 자료이며 원작의 모든 장면·분기·샤드와 한국어판 대사를 완전히 수록한 자료는 아니다. 현재 인물 카드·판단·예시·인지 조건은 draft다. 12명 모두 [개발용 인물 설정·테스트](dialogue-prototype.md#인물-설정과-대화-테스트)에 연결했다. 실제 게임은 연결하지 않았다. 공개 사실이 있다고 그 인물이 현재 V와 자유롭게 대화할 수 있는 것으로 처리하지 않는다.

기술 절차는 [The Information](https://cyberpunk.fandom.com/wiki/The_Information)의 튜토리얼 목표, 타로는 [Misty](https://cyberpunk.fandom.com/wiki/Misty_Olszewski)·[Tarot Cards](https://cyberpunk.fandom.com/wiki/Tarot_Cards)·[Fool on the Hill](https://cyberpunk.fandom.com/wiki/Fool_on_the_Hill)의 발췌, 밴드·계약은 [Samurai](https://cyberpunk.fandom.com/wiki/Samurai)·[MSM Records](https://cyberpunk.fandom.com/wiki/MSM_Records)로 보완했다. 인물 이력별 URL은 각 사실의 source에 기록한다.

팬 위키 본문 접근은 제한되어 검색 발췌로 확인했다. 공식 코스플레이 목록을 확인했으나 이번에 시도한 미스티·에블린·케리·타케무라 PDF는 크기 제한으로 본문을 읽지 못했다. 해당 PDF를 직접 확인한 출처로 기록하지 않았다. 기존 Ultimate Edition 안내서의 과거 열람 기록과 이번 접근 실패를 구분한다. 이번 보강은 게임을 직접 플레이하며 전체 인지·한국어 말투를 검수한 결과가 아니다.

[CDPR 공식 인물 소개](https://www.cyberpunk.net/en/cyberpunk-2077)에서 주디·팬앰·재키와 조니 등의 기본 소개를 읽었다. [CDPR 공식 Ultimate Edition 안내서](https://cdn-s-cyberpunk.cdprojektred.com/CP2077-UE-Booklet-EN-1.pdf)의 인물 소개·현지화 절도 별도로 텍스트를 추출해 읽었다. 웹 도구에서는 이 PDF가 크기 제한으로 열리지 않았으나 로컬 PDF 라이브러리로 본문 확인에 성공했다.

공식 안내서는 빅터의 돌봄, 미스티의 차분한 상담, 리버의 도덕적 갈등과 가족 보호, 타케무라의 경력 등을 보완하는 자료다. 한국어 문체를 영어 억양의 기계적인 모방으로 만들 수 있다는 근거로 사용하지 않는다. 언어마다 발화 방식·어휘를 다르게 조정한다는 현지화 설명을 한국어판 장면 검수 필요성에 반영했다.

기본 출처를 보완한 2차 자료: [빅터](https://cyberpunk.fandom.com/wiki/Viktor_Vektor), [미스티](https://cyberpunk.fandom.com/wiki/Misty_Olszewski), [로그](https://cyberpunk.fandom.com/wiki/Rogue_Amendiares), [타케무라](https://cyberpunk.fandom.com/wiki/Goro_Takemura), [케리](https://cyberpunk.fandom.com/wiki/Kerry_Eurodyne), [리버](https://cyberpunk.fandom.com/wiki/River_Ward), [에블린](https://cyberpunk.fandom.com/wiki/Evelyn_Parker). 일부 팬 위키 본문은 접근 제한이 있어 검색 도구가 제공한 설명·Database Entry 발췌로 확인했다. 전체 본문을 열람하거나 게임 원본을 직접 확인한 것으로 기록하지 않았다.

지역 자료는 [CDPR 도시 장소 안내](https://www.cyberpunk.net/en/news/50110/your-trip-to-night-city-best-spots-for-street-photography)를 포함한다. 기술·집단·통화 등 나머지 항목의 개별 근거와 확인 방법은 [출처 목록](../content/cyberpunk2077/sources.json), 사실과 연결된 근거는 [세계관 자료](../content/cyberpunk2077/world-facts.json)에 기록했다. 자료 원문을 통째로 복제하지 않고 짧은 최소 진술로 작성했다.

## 4. 확정하지 않은 항목

- 케리의 악기는 공식 안내서와 위키 표현이 달라 등록하지 않았다. SAMURAI 활동과 솔로 경력만 사용한다.
- 한국어판의 반말·존댓말·호칭·욕설·실제 대사 리듬은 이번 웹 자료만으로 확정하지 않았다.
- 카드의 단계 이름은 설계용 논리 이름이다. 실제 게임의 퀘스트 플래그와 연결된 상태가 아니다.
- 공개 위키에서 미래 사건을 알 수 있어도 캐릭터의 현재 지식으로 넣지 않았다. 렐릭 관련 후보에는 인지 확인과 V의 공개 허용을 요구했다.
- 직업상 알 법한 지식은 배분 후보로 작성했다. 모든 전문 지식의 실제 원작 인지 여부를 확인한 것으로 처리하지 않는다.

## 5. 군중 NPC로 확장하는 기준

다음 단계에서는 배달원·정비 노동자·기업 근로자·상점 직원·의료 종사자·경비·넷 업무 종사자·외곽 생활자 등의 원형을 작성한다. 직업은 관찰 또는 승인 배경으로 확인할 수 있을 때만 부여한다. 원형별 신규 성격 생성 프로필·판단 규칙·문체를 검수하고 지식 묶음을 연결한다.

이번 단계에는 지식 배분 정책과 후보 묶음까지 포함했다. 완성된 군중 원형·특성 풀은 아직 만들지 않았다. 실제 생성기 구현과 인물별 품질 비교의 순서는 [개발·검증 계획](development-validation.md)이 기준이다.

## 6. 인터뷰 확정 범위와 자료 적용

갱신: 2026-10-01. 이 조사 문서는 기존 10명 자료의 근거·보류 상태를 유지한다. 최신 동작은 [초기 명세](initial-design.md)와 분야별 기준 문서에서 정의하며 이번 개정으로 인물 카드·일상 정책·한국어 말투를 출시 승인하지 않는다.

- 고유 인물의 기존 선택지 진입·자유 상태·제어 반환은 인물별 지원 매핑이 필요하다. 사망·연출·현재 관계를 웹 소개로 고정하지 않는다.
- 현재 진행도에 맞는 원작 경험·지식·목표·관계 맥락을 작성하고 원작 대사 전체를 ANPC 이력으로 복제하지 않는다.
- 복장 평가에는 현재 외형 텍스트와 같은 인물의 실제 관찰 기억을 사용한다. 친밀한 표현은 현재 원작 관계와 한국어 문체의 검수 범위에서 작성한다.
- 승인 가능한 사소한 일상 소재를 인물별 생활/현재 단계에 맞춰 작성하되 원작 과거·새 관계·전문 경험을 늘리지 않는다. 기준은 [일상 정책](content-specification.md#91-사소한-일상-창작-정책)이다.
- 향후 제스처 선호는 인물 행동 정책에 작성한다. 기존 모드의 실제 재생·취소·골격 호환 여부를 확인한 후보만 실행용으로 연결한다.

## 조니 실버핸드

- 고정 정체성: 반기업 로커보이·전 SAMURAI 프런트맨. 2077년 V의 렐릭 속 인격 엔그램.
- 전문 범위: 음악·자기 생전 경험. 기업·용병 활동은 역할 기반 상한. 치료·넷러닝 전문가로 확대 금지.
- 원작 관계: 각성 초기 적대 / 공동 생존 협력 / 유전지대 두 번째 기회 / 신뢰 거절 / 재결합 공연 동료 / 렐릭 분리 발화 불가. 대화 누적 승격 없음.
- 과거 회고는 자기 시점. 독립 육체·타 NPC와의 직접 대화·합의 없는 V 신체 통제·미래 사건 확정 금지.
- 원작 사실 근거: [CDPR 인물 소개](https://www.cyberpunk.net/us/en/cyberpunk-2077), [인물·Database 정리](https://cyberpunk.fandom.com/wiki/Johnny_Silverhand), [Tapeworm](https://cyberpunk.fandom.com/wiki/Tapeworm), [Chippin’ In](https://cyberpunk.fandom.com/wiki/Chippin%27_In_%28quest%29), [SAMURAI](https://cyberpunk.fandom.com/wiki/Samurai). 말투·Big Five·개별 인지 배분은 작성 해석이며 출시 검수 필요.

## 송버드 관계 단계

초기 구조 거래·구조 협력·Black Sapphire·탈출 계획·소미 경로의 우주공항·열차 고백·리드 경로의 코어를 구분한다. 달 출발·FIA 구금·사망은 새 대화 불가로 둔다. 관계 단계의 과거 사건은 선택한 경로의 최소 요약이며 세부 비밀은 별도 지식 공개 조건을 유지한다.
