# 대표 커뮤니티 NPC 10명 및 세계관 자료 조사

작성일: 2026-09-30. 선정한 인물 10명의 기본 배경·정체성 방향·전문 지식·대화 제한을 조사하고 콘텐츠 파일로 정리했다. 원작 사실과 작성 해석은 별도 필드로 저장했다. 콘텐츠의 기준 데이터는 [자료 목록](../content/cyberpunk2077/manifest.json), 배분 기준은 [NPC 지식 규격](npc-knowledge-specification.md)이다.

## 1. 정리한 범위

- 인물 카드 10개: 배경, 신념·욕구·두려움·금기, 판단 규칙, 문체 방향, 대체 대사, 단계, 지식·예시 참조.
- 세계관 사실 53개: 도시·통화·신체 개조·기술·기업·의료·치안·지역·집단·음악·렐릭과 인물의 기본 배경.
- 인물별 지식 후보 154개: 같은 사실을 인물별 인지·공개·해석 조건으로 참조.
- 새 상황의 대사 예시 20개: 인물별 2개. 원작 대사 인용이나 실제 모델 응답이 아닌 검수 전 작성 예시.
- 군중 지식 묶음 후보 13개: 공통, 지역 7개, 직업 4개, 선택 관심 목록.

10명 전체를 정리한 초기 자료이며 원작의 모든 장면·분기·샤드와 한국어판 대사를 완전히 수록한 자료는 아니다. 현재 인물 카드·판단·예시·인지 조건은 draft다. 10명 모두 [개발용 인물 설정·테스트](dialogue-prototype.md#인물-설정과-대화-테스트)에 연결했다. 실제 게임은 연결하지 않았다. 공개 사실이 있다고 그 인물이 현재 V와 자유롭게 대화할 수 있는 것으로 처리하지 않는다.

## 2. 인물별 작성 방향

이 표의 판단·문체는 자료를 읽고 작성한 초안이다. 실제 원작 장면의 반응과 한국어 표현을 검수한 뒤 승인한다. 아래 카드에는 같은 구조의 상세 데이터와 각 인물의 전문 지식 후보를 포함했다.

| --- | --- | --- | --- |

### 2.1. 출신·역할별 지식 상한 보완

2026-10-01에 10개 카드 모두에 knowledge_profile과 근거 구분을 추가했다. 아래는 현재 작성 상한·보류 사항의 안내이며 승인된 원작 인지 판정이 아니다. 분야별 실제 값은 각 카드가 기준이고 객체 계약은 [콘텐츠 규격](content-specification.md#41-인물별-분야와-지식-깊이)에 둔다.

| 인물 | 확인된 배경을 활용할 분야 | 별도 근거가 필요한 확대 해석 |
| --- | --- | --- |
| 주디 | BD 제작·편집, 리즈 바·목스 활동 | BD 기술자라는 이유로 넷러너·의료 전문가로 확대 |
| 팬앰 | 노마드·알데칼도 생활, 용병 일 | BD 개요·제작·이용 경험의 자동 부여. 원작상 BD 무지라는 확정도 보류 |
| 재키 | 헤이우드 배경, 용병 생활 | 모든 도시 갱의 내부 사정·기술 전문성 |
| 빅터 | 리퍼닥 진료·사이버웨어 업무 | 의료 역할로 BD 편집·넷러닝을 전문 설명 |
| 미스티 | 가게·상담·자기 배경 | 주변 진료소와 가깝다는 이유로 의료 실무·정확한 미래 예측 |
| 로그 | 용병 경력·픽서 업무 | 계약 인맥을 근거로 모든 작전 비밀·기업 네트워크 기술 인지 |
| 타케무라 | 아라사카 경호 경력 | 물리적 경호 경험을 넷러닝·기업 전체 기밀로 확대 |
| 케리 | SAMURAI·솔로 음악 활동 | 유명세를 BD 제작·기업 보안 전문성으로 확대 |
| 리버 | 경찰 수사 경력 | 사건별 근거 없이 BD 편집 전문가·현재 경찰 내부자로 표현 |
| 에블린 | 클라우드 관련 배경·자기 경험 | 주디와의 관계로 BD 편집 전문성·주디의 모든 지식 부여 |

기존 목록에는 공통 BD 개요, 일부 인물의 BD 편집·기업 네트워크 기술 후보가 포함돼 있었다. 삭제로 조사 이력을 감추지 않고 미확인 분야 상한으로 제공을 차단했다. 공개 소개가 개별 지식의 인지 증거는 아니므로 생활 상식 후보도 authored_candidate로 남긴다. 팬앰의 BD 경험 여부를 소개만으로 판정하지 않는다.

## 3. 조사 근거와 접근 한계

[CDPR 공식 인물 소개](https://www.cyberpunk.net/en/cyberpunk-2077)에서 주디·팬앰·재키와 조니 등의 기본 소개를 읽었다. [CDPR 공식 Ultimate Edition 안내서](https://cdn-s-cyberpunk.cdprojektred.com/CP2077-UE-Booklet-EN-1.pdf)의 인물 소개·현지화 절도 별도로 텍스트를 추출해 읽었다. 웹 도구에서는 이 PDF가 크기 제한으로 열리지 않았으나 로컬 PDF 라이브러리로 본문 확인에 성공했다.

공식 안내서는 빅터의 돌봄, 미스티의 차분한 상담, 리버의 도덕적 갈등과 가족 보호, 타케무라의 경력 등을 보완하는 자료다. 한국어 문체를 영어 억양의 기계적인 모방으로 만들 수 있다는 근거로 사용하지 않는다. 언어마다 발화 방식·어휘를 다르게 조정한다는 현지화 설명을 한국어판 장면 검수 필요성에 반영했다.

기본 출처를 보완한 2차 자료: [빅터](https://cyberpunk.fandom.com/wiki/Viktor_Vektor), [미스티](https://cyberpunk.fandom.com/wiki/Misty_Olszewski), [로그](https://cyberpunk.fandom.com/wiki/Rogue_Amendiares), [타케무라](https://cyberpunk.fandom.com/wiki/Goro_Takemura), [케리](https://cyberpunk.fandom.com/wiki/Kerry_Eurodyne), [리버](https://cyberpunk.fandom.com/wiki/River_Ward), [에블린](https://cyberpunk.fandom.com/wiki/Evelyn_Parker). 일부 팬 위키 본문은 접근 제한이 있어 검색 도구가 제공한 설명·Database Entry 발췌로 확인했다. 전체 본문을 열람하거나 게임 원본을 직접 확인한 것으로 기록하지 않았다.

지역 자료는 [CDPR 도시 장소 안내](https://www.cyberpunk.net/en/news/50110/your-trip-to-night-city-best-spots-for-street-photography)를 포함한다. 기술·집단·통화 등 나머지 항목의 개별 근거와 확인 방법은 [출처 목록](../content/cyberpunk2077/sources.json), 사실과 연결된 근거는 [세계관 자료](../content/cyberpunk2077/world-facts.json)에 기록했다. 자료 원문을 통째로 복제하지 않고 짧은 최소 진술로 작성했다.

## 4. 확정하지 않은 항목

- 케리의 악기는 공식 안내서와 위키 표현이 달라 등록하지 않았다. SAMURAI 활동과 솔로 경력만 사용한다.
- 한국어판의 반말·존댓말·호칭·욕설·실제 대사 리듬은 이번 웹 자료만으로 확정하지 않았다.
- 카드의 단계 이름은 설계용 논리 이름이다. 실제 게임의 퀘스트 플래그와 연결된 상태가 아니다.
- 공개 위키에서 미래 사건을 알 수 있어도 캐릭터의 현재 지식으로 넣지 않았다. 렐릭 관련 후보에는 인지 확인과 V의 공개 허용을 요구했다.
- 직업상 알 법한 지식은 배분 후보로 작성했다. 모든 전문 지식의 실제 원작 인지 여부를 확인한 것으로 처리하지 않는다.

## 5. 군중 NPC로 확장하는 기준

다음 단계에서는 배달원·정비 노동자·기업 근로자·상점 직원·의료 종사자·경비·넷 업무 종사자·외곽 생활자 등의 원형을 작성한다. 직업은 관찰 또는 승인 배경으로 확인할 수 있을 때만 부여한다. 원형별 슬롯 풀·판단 규칙·문체를 검수하고 지식 묶음을 연결한다.

이번 단계에는 지식 배분 정책과 후보 묶음까지 포함했다. 완성된 군중 원형·특성 풀은 아직 만들지 않았다. 실제 생성기 구현과 인물별 품질 비교의 순서는 [개발·검증 계획](development-validation.md)이 기준이다.
