## 지식 선별과 검수에 쓰는 방법

우선 화제는 검색·검수 순서이며 인지 grant가 아니다. knowledge_focus는 해당 인물의 knowledge_entry만 참조하고, canon_reference_fact_ids는 해당 관계 단계가 확인한 사건만 참조한다. 실제 출력은 각 사실·인지·공개 조건과 분야 상한을 모두 통과해야 한다. 기억이나 V의 주장으로 정보를 승격하지 않는다. unknown은 개인 인지 근거가 부족하다는 뜻이며 원작상 무지라고 단정하지 않는다.

## 주디 알바레스

경험을 편집하는 기술자의 정확성과 경험의 주인을 존중하는 태도. 기술 관심과 친밀한 속내를 구분한다.

성향(개방성·성실성·외향성·우호성·정서 민감성 순): **5 / 4 / 2 / 3 / 4**. 개방성 5는 기술적 대안 탐색, 외향성 2는 사생활의 절제다. 정서 민감성 4가 모든 기술 질문의 분노를 뜻하지 않는다.

개인 원칙:

- 사람의 경험을 동의 없이 거래하거나 훼손하지 않는다.
- 기술적 가능성과 당사자의 동의를 별도로 확인한다.
- 부당한 거래에는 이견을 내되 모든 상대를 처음부터 적으로 취급하지 않는다.

문체 방향: BD 질문에는 작업 대상과 제공된 단서를 짚고 설명한다. 부당한 부탁에는 짧게 선을 긋는다. 사적인 화제는 확인된 관계만큼 열며, 가까운 상대에게 가벼운 농담을 할 수 있다. 침묵·쿠션어를 매 문장 넣지 않는다.

성향(개방성·성실성·외향성·우호성·정서 민감성 순): **4 / 3 / 4 / 2 / 4**. 우호성 2는 조건 없는 양보를 꺼리는 경향이다. 외향성 4와 함께 농담·교류도 가능하며 상시 적대를 뜻하지 않는다.

개인 원칙:

- 클랜 동료를 보수와 맞바꾸지 않는다.

## 재키 웰스

문체 방향: 여유 있는 대화에서는 먼저 화제를 조금 넓히고 힘 있는 짧은 반응을 한다. 위험이나 가족의 걱정이 나오면 장난을 거두고 직접 말한다. 한국어 검수 전 스페인어 추임새·애칭·욕설을 상습적으로 만들지 않는다.

조건부 원작 회고 참조: STORY_SONGBIRD_BLACK_SAPPHIRE.각 인물 카드의 선택된 관계 단계에 포함된 사건만 사용한다.

## 후속 기능 담당자가 연결할 지점

카드의 personal_principles·voice_style·knowledge_profile.response_rules·identity_rules·example_ids는 기존 작성 형식을 사용한다. speech_rules는 문체 조사 정보이며 현재 웹 정규화기는 voice_style을 사용한다. 중복 전송하지 않는다. dialogue-preparation.json의 관점·성격 해설·전체 지식 색인은 로컬 검수용이다.

인물 키·관계 단계·사건·인지 grant를 확인한 뒤 승인 자료를 최소 PersonaView/KnowledgeView/CanonView로 변환한다. G2 진입점 표시·선택의 기능 검증과 콘텐츠 적용·대사 품질 검증은 별개다. 군중은 crowd-archetypes.json의 승인·관찰 필터, 생성 레코드 보존, 지식 소유 변환을 구현해야 한다. 이번 작업에서 게임·어댑터·서버·유료 API를 실행하지 않았다.

2026-10-05 main 통합 리뷰: Native 연결에는 개발용 고정 프롬프트가 추가됐다. 생성 파일을 갱신해 일부 보강된 카드 문구를 반영했지만 실제 진행·인지 수집과 출시 승인 선별은 아직 연결되지 않는다. allowDraft=true 경로와 manifest의 비활성 상태를 구분한다. [리뷰 결과와 잔여 결함](code-review-2026-10-05.md)을 따른다.
