# NPC 행동 범위 명세

규격 버전: 0.1 (2026-09-30). 이 문서는 ANPC가 제공할 행동의 의미·인수·권한·결과를 정의한다. 현재 게임 동작이 확인됐다는 의미는 아니다. 구현 근거는 [참고 분석](benchmark-analysis.md), 시험 절차는 [개발·검증 계획](development-validation.md)에 둔다.

## 1. 범위와 권한

행동은 기본 범위와 확장 범위로 구분한다. 기본 범위는 텍스트 대화에 필요한 제어·시선·짧은 이동이다. 확장 범위는 동행·자산 연출·차량·거래다. 배포 프로필에 실행기가 등록되고 대상 기능·인물 카드·현재 상태가 허용한 행동만 요청 목록에 포함한다. 실행기가 없는 행동은 목록에서 제외한다.

최종 허용 목록은 배포 지원 목록 ∩ NPC 기능 ∩ 캐릭터 카드 ∩ 현재 게임 상태다. 커뮤니티는 원작 역할과 금기를 유지한다. 군중은 현재 살아 있는 인스턴스에만 명령을 실행한다. AI는 요청당 행동 하나를 제안하며 코드를 실행하거나 게임 자산 경로를 지정할 수 없다.

위치·차량·워크스팟·소품·제스처는 모드가 발급한 후보 ID로 지정한다. AI가 원시 좌표·엔티티 ID·파일 경로·아이템 ID를 새로 만들 수 없다. 모든 단위는 미터·초이며 아래 수치는 초기 제품 정책 기본값이다.

## 2. 공통 행동 계약

입력은 action_request_id, session_id, request_id, npc_instance_key, action_id, args다. 동일 action_request_id의 재전달은 원래 결과를 반환하고 중복 실행하지 않는다.

상태는 proposed → accepted → running → succeeded/failed/cancelled다. 조건 거부는 rejected로 끝낸다. 반환 필드는 action_request_id, status, reason_code, started_at, ended_at, observed_effect다. succeeded는 실제 완료 조건을 만족했을 때만 사용한다.

거부·실패 사유는 unsupported, forbidden, invalid_args, stale_target, unsafe_state, unreachable, occupied, timeout, interrupted, adapter_error다. 행동 거부만으로 유효한 대사를 삭제하지 않는다. 완료 전에는 행동을 이미 수행했다는 대사를 확정하지 않는다.

동시에 이동 또는 전신 연출 하나만 실행한다. 새 명령은 기존 ANPC 명령을 정리한 뒤 시작한다. 시선은 실행기가 허용하는 경우에만 병행한다. 원작 명령을 일괄 취소하지 않는다.

## 3. 기본 행동

| ID | 허용 인수 | 명세 | 완료·한도 |
| --- | --- | --- | --- |
| stop_and_listen | 없음 | 대화 동안 ANPC 소유 위치 유지 | 유지 상태 진입 시 완료. 세션 종료 시 해제 |
| face_player | duration_s: 1~10 | 플레이어에게 머리·눈 시선 설정. 전신 회전은 포함하지 않음 | 시선 설정 확인. 기본 3초 후 해제 |
| look_at_target | target_ref, duration_s: 1~10 | 허용된 주변 대상에게 시선 설정 | 대상 유효·시선 설정 확인. 기본 3초 |
| resume_walk | 없음 | ANPC 소유 정지·이동·시선 제어 해제 | 제어 잔류 없음. 실제 보행 재개를 의미하지 않음 |
| end_conversation | 없음 | 세션 종료 요청 | 통신 응답 무효화와 모드 제어 해제 |
| move_to_point | destination_ref | 같은 로컬 공간의 안전 후보로 이동 | 출발점에서 최대 5m, 도착 오차 0.75m, 제한 10초 |
| step_back | distance_m: 0.5~2 | 후방의 안전 위치로 짧게 이동 | 기본 1m, 도착 오차 0.75m, 제한 5초 |
| approach_player | stop_distance_m: 1.5~3 | 플레이어의 현재 위치 근처로 접근 | 기본 간격 2m, 이동 최대 5m, 제한 10초 |
| wait_here | duration_s: 1~30 | 지정 시간 현재 위치 유지 | 시간 경과 후 해제. 기본 5초 |
| return_to_anchor | 없음 | 세션 시작 시 기록한 안전 위치로 이동 | 최대 5m, 도착 오차 0.75m, 제한 10초 |

이동 목적지는 같은 높이·길찾기 가능 공간이어야 한다. 차도·낙차·닫힌 장애물·점유 위치는 제외한다. 판정 정보가 없으면 실행을 거부한다. 이동 실패 시 ANPC 제어를 해제하며 일반 행동으로 순간이동하지 않는다.

stop_and_listen은 모델 응답을 기다리기 위해 세션 관리자가 실행할 수 있다. 위치 유지와 대화의 전체 수명은 세션 관리자에 귀속되며 행동 완료 이후에도 종료 정리 대상으로 기록한다.

## 4. 이동 확장

| ID | 허용 인수 | 명세 | 완료·한도 |
| --- | --- | --- | --- |
| follow_player | duration_s: 1~60 | 플레이어와 2~4m 간격을 목표로 동행 | 기본 30초 또는 세션 종료. 종료 거리 정책 우선 |
| guide_to_location | route_ref | 작성된 지역 경로를 따라 안내 | 경로 최대 30m·60초. 플레이어 8m 이탈 시 대기 |
| walk_short_route | route_ref | 작성된 경유점을 순서대로 이동 | 최대 5개 경유점·30m·60초 |

추격·순간이동·새 지역 진입은 포함하지 않는다. 대화 종료 거리 10m에 도달하면 명령과 세션을 정리한다. 안내 대기는 최대 10초이며 그 안에 플레이어가 돌아오지 않으면 interrupted로 끝낸다.

각 자산 항목에는 호환 골격·인물, 점유 슬롯, 길이, 종료 이벤트, 퇴장 동작, 복구 처리를 등록한다. 완료 이벤트 없이 길이만으로 종료하는 실행기는 자산 메타데이터의 길이와 해제 결과를 함께 확인한다. 기존 워크스팟을 강제로 빼앗지 않는다. 미등록 동작·표정·소품은 거부한다.

## 6. 차량·거래 확장

| ID | 허용 인수 | 명세 | 완료·한도 |
| --- | --- | --- | --- |
| enter_vehicle_passenger | vehicle_ref, seat_ref | 정지 차량의 빈 승객 좌석 탑승 | 실제 탑승 상태 확인. 최대 15초 |

| equip_allowed_item | equipment_ref | 허용 슬롯·장비 프리셋 적용 | 실제 슬롯 확인. 최대 5초 |

군중의 차량 운전·무장 변경·보상 지급은 기본 금지다. 퀘스트 장비와 원작 경제 데이터를 덮어쓰지 않는다. 지급 동작은 손으로 건네는 애니메이션을 포함하지 않는다. 실패 또는 취소 후 완료 여부가 불명확한 거래는 재실행하지 않고 오류를 반환한다. 운전은 별도 후속 이동 세션에만 허용하며 초기 대화 세션에서는 실행하지 않는다.

## 7. 콘텐츠 조합

react_to_other_npc와 greet_on_recontact는 실행 행동 ID가 아니라 콘텐츠 의도다. 전자는 look_at_target 또는 play_gesture와 대사를, 후자는 유효 기억과 face_player 또는 대사를 조합한다. 모델 응답의 action_id에 이 의도를 넣으면 거부한다. 실제 실행 목록은 앞 절의 27개 ID로 한정한다.

## 8. 중단·복구 의무

세션 종료·전투·퀘스트 제어·세계 전환·대상 소멸은 실행 중 행동을 취소한다. ANPC 소유 명령·시선·장비 변경·임시 소품·엔티티만 정리한다. 이전 상태를 복구할 때 현재 원작 상태와 충돌하면 복구 덮어쓰기를 생략하고 원작 제어를 우선한다. 대상이 소멸하면 객체 호출 없이 내부 참조만 폐기한다. 정리는 반복해도 같은 결과여야 한다.

## 9. 범위 밖

임의 퀘스트 변경, 도망·엄폐·항복·공격 명령, 임의 문·터미널 조작, 악수 등 동시 배우 동작, 실시간 립싱크 생성, 자율 생활 일정, 군중 영속화는 현재 행동 계약에서 제외한다. 확장 범위의 정의는 지원 완료 선언이 아니며 배포 프로필의 지원 여부가 실행 권한을 결정한다.
