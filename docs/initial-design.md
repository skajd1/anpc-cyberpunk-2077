# ANPC 초기 버전 명세

규격 버전: 0.1 (2026-09-30). 첫 배포에 포함할 기능과 제외 범위를 정의한다. 개발 순서와 시험 방법은 [개발·검증 계획](development-validation.md)에 둔다.

## 1. 지원 범위

길거리에서 걷는 군중과 자유 상태의 지원 커뮤니티 NPC를 대상으로 한다. 커뮤니티는 등록된 카드가 있어야 한다. 플레이어는 조준한 NPC에게 텍스트로 말을 건다. 동시 대화는 한 명으로 제한한다.

## 2. 포함 기능

| 구성 | 초기 제공 범위 |
| --- | --- |
| 입력·화면 | NPC 선택, 채팅 기록·입력, 대기·취소·종료, 오류 표시 |
| AI 연결 | 개인 API 키, 비동기 텍스트 요청, 형식 검사, 오류·취소 처리 |
| 인물 | 군중 원형 기반 특성, 지원 커뮤니티 카드 |
| 상황 | 알려진 노출 장비·무기 상태·지역과 인물에게 허용된 지식 |
| 상태 확장 | 레벨·평판·퀘스트·관계는 수집 어댑터와 인지 규칙이 있는 필드만 활성화 |
| 행동 | stop_and_listen, face_player, resume_walk, end_conversation |
| 기억 | 같은 살아 있는 인스턴스의 근거리 재접촉 기억과 사용자 삭제 |
| 보호 | 원작 제어 우선, 잘못된 대상·늦은 응답 차단, 종료 정리 |

초기 행동 중 지원 실행기가 없는 경우 해당 배포 대상은 지원하지 않는다. 행동 실패 시 텍스트로 축소하더라도 제어 해제와 원작 보호는 필수다.

## 3. 실행과 데이터

기본 구성은 게임 내부 모듈과 콘텐츠·설정 파일이다. 별도 로컬 브리지는 필수가 아니다. 구체 계약은 [통신](runtime-specification.md), [NPC 식별](npc-identity-specification.md), [게임 정보](game-context-specification.md), [콘텐츠](content-specification.md), [행동](npc-action-scope.md)을 따른다.

## 4. 제외 기능

동행·안내·생활 동작·차량·거래, NPC 음성, 플레이어 음성, 장기 기억, 로컬 모델, 퀘스트 중 인물 제어, 군중 재생성 후 동일성 복원은 첫 배포에서 제외한다. 이동은 행동 명세의 기본 범위에 정의되어 있으나 첫 배포 활성 목록에는 포함하지 않는다.
