# ANPC 초기 설계

상태: 초안 (2026-09-29). 이 문서는 첫 플레이 가능 버전과 기술 검증 순서를 정한다. 목표 기능 전체는 [전체 스펙](full-specification.md)에 있다.

## 목표

플레이어가 사이버펑크 2077의 길거리 군중 NPC 또는 지원되는 커뮤니티 NPC에게 먼저 대화를 건다. 텍스트 채팅으로 여러 차례 대화하고, NPC가 허용된 행동 하나를 보인 뒤 대화를 끝내면 원래 상태로 복귀한다. 대화가 시작된 이후 NPC는 질문이나 반응을 먼저 제안할 수 있다.

첫 실험 대상은 **걷는 군중 NPC 1명과 퀘스트 중이 아닌 커뮤니티 NPC 1명**이다. AI 모델 연결에 앞서 고정 대사로 선택·UI·상태 읽기·행동·복구의 전체 경로를 검증한다.

## 선행 기술 검증

| 항목 | 확인할 것 | 통과 기준 |
| --- | --- | --- |
| NPC 선택 | 근처 또는 조준한 NPC를 식별하고 군중/커뮤니티로 분류 | 다른 대상을 잘못 선택하지 않는다. |
| 수명 관리 | 군중 NPC가 이동·소멸할 때 대화 세션 처리 | 대상이 사라져도 게임과 UI가 정상이다. |
| 채팅 UI | 입력, 대화 기록, 대기 표시, 취소·종료 | 입력 중 게임 조작 키가 함께 작동하지 않는다. |
| 게임 정보 | 레벨, 길거리 평판, 장착·노출 장비, 지역, 진행도 | 각 값의 실제 접근 가능 여부와 출처를 확인한다. |
| 행동 | 돌아보기 등 안전한 반응 하나 실행 | 종료·중단 시 원래 행동으로 돌아간다. |
| 퀘스트 보호 | 기존 대화·연출 감지 | 진행 중인 게임 연출을 ANPC가 가로채지 않는다. |

군중 NPC를 대화 중 안정적으로 붙잡지 못하면, 먼저 NPC가 근처에 있는 동안만 작동하는 짧은 대화로 시제품을 만들고 제어 방법을 별도 조사한다. 군중 NPC 요구를 임의로 생성한 전용 NPC로 대체하지 않는다.

## 구현 구조

```text
게임 모드: NPC 선택 + 게임 상태 + 채팅 UI + 행동 실행 + 복구
    ↕
로컬 프로그램: 캐릭터 설정 + 기억 + 프롬프트 + AI 호출 + 응답 검사
    ↕
선택한 AI 제공자
```

게임 프레임을 기다리게 하지 않도록 AI 요청은 비동기로 처리한다. AI는 `대사`와 미리 등록된 `행동 ID`만 제안할 수 있고, 게임 모드가 해당 NPC와 순간의 게임 상태에서 가능한 행동인지 최종 검사한다. 인증 정보는 Git에 올리지 않는 로컬 설정에 보관한다.

첫 UI 실험에는 Cyber Engine Tweaks(CET)의 Lua·오버레이를 검토한다. 더 깊은 훅은 redscript, Codeware, RED4ext로 검증하고, 자산 제작이 필요하면 WolvenKit·REDmod를 검토한다. 특정 기능을 실제로 사용할 수 있다는 뜻은 아니며 게임에서 확인해야 한다.

## NPC별 초기 정책

- **군중 NPC:** 지역, 현재 활동, 기질, 말투, 플레이어에 대한 태도로 특성을 한 번 생성한다. 세션 중 고정한다. 재등장한 NPC를 안정적으로 식별하기 전에는 장기 기억을 약속하지 않는다.
- **커뮤니티 NPC:** 수작업으로 작성한 캐릭터 프로필을 적용한다. 성격, 말투, 관계, 해당 퀘스트 단계에서 아는 사실을 유지한다. 기존 퀘스트 연출 중에는 ANPC를 비활성화한다.

## 개발 순서

1. 게임 버전과 모딩 도구 호환성을 고정하고 NPC 선택을 기록하는 작은 테스트 모드를 만든다.
2. 군중·커뮤니티 NPC의 채팅 시작/종료와 중단 처리를 고정 대사로 구현한다.
3. 실제 플레이어 상태 일부를 읽고 NPC의 안전한 행동 하나를 연결한다.
4. 로컬 프로그램과 AI를 연결하고 응답 지연·취소·오류 복구를 처리한다.
5. 군중 특성 생성과 커뮤니티 캐릭터 프로필을 넣는다.
6. 행동 종류, 기억, 지원 NPC 범위를 검증된 것부터 확대한다.

## 첫 성공 시나리오

플레이어가 걷는 군중 NPC에게 채팅으로 말을 건다. NPC는 관찰 가능한 플레이어 상태 하나를 반영해 답하고, 검증된 반응 하나를 보인다. 플레이어가 채팅을 닫으면 NPC는 정상 행동으로 돌아간다. 커뮤니티 NPC에서도 동일한 흐름이 작동하되 작성된 성격과 말투를 지킨다. 전투나 NPC 소멸 시 두 세션 모두 안전하게 끝난다.

## 현재 제약과 결정 대기 사항

- 이 PC에는 사이버펑크 2077이 없어 게임 API와 NPC 동작을 아직 검증할 수 없다.
- 군중 NPC의 선택·제어·재식별 가능성은 각각 별도의 실험이 필요하다.
- AI 제공자, 로컬/원격 실행, 응답 시간 및 비용 기준은 구현 전 결정한다.
- 플레이어 음성 입력은 초기 범위에서 제외한다.
