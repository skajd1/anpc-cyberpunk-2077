# ANPC 초기 버전 명세

규격 버전: 0.3 (2026-10-01). 인터뷰에서 확정한 현재 시제품·첫 게임 연동 버전·후속 확장의 경계를 정의한다. 첫 게임판의 목표를 현재 구현 완료로 해석하지 않는다. 개발 순서와 시험 상태는 [개발·검증 계획](development-validation.md)에 둔다.

## 1. 지원 범위

길거리 군중과 원작 제어에서 자유로운 지원 커뮤니티 NPC를 대상으로 한다. 커뮤니티는 승인 카드·게임 인물·진행도·관계 매핑이 필요하다. 동시 대화는 한 명이며 플레이어 입력은 텍스트다. 군중 정체성은 유효한 동일 인스턴스에서 고정하고 커뮤니티 정체성은 원작 기준으로 고정한다. 신규 핵심 성격은 [Big Five 규격](personality-specification.md)을 따른다. 기존 시제품의 세 특성 슬롯은 전환 전 형식이다.

## 2. 단계별 포함 기능

| 구성 | 현재 웹 시제품의 상태 | 첫 게임 연동 버전의 목표 |
| --- | --- | --- |
| 진입 | 인물 선택 후 추가 대화 버튼으로 모의 진입 | 커뮤니티는 기존 선택지 아래 추가 선택지, 군중은 짧은 기본 반응 후 추가 선택지. 절차는 [NPC 식별 규격](npc-identity-specification.md) |
| 입력·출력 | 채팅 입력과 대사 텍스트 표시 | 채팅 입력·기록과 NPC 대사 자막, 대기·취소·종료·오류 UI. 자막 계약은 [통신 규격](runtime-specification.md) |
| 연결 | 모의 응답·개인 API·개발용 Codex 연결 | 개인 API 키와 비동기 요청·형식 검사·오류·취소 처리. 제작자 서버 없음 |
| 정체성·지식 | 창작 카드와 명시적으로 허용한 조사 초안 | 승인된 인물·군중 데이터, 진행도별 원작 기억·지식·관계 맥락 |
| 복장 | 표시 복장 이름/설명·목격 기록을 모의 입력 | 실제 표시 복장의 아이템 이름·외형 텍스트와 해당 NPC가 관찰한 이전 복장. [게임 정보 규격](game-context-specification.md) |
| 평판 | 공개 이름 인지 모의 플래그. 실제 평판 매핑 없음 | 승인된 평판 임계 규칙에 따라 처음 만난 시민도 V의 이름·공개 행적 인지 가능 |
| 기본 제어 | 기본 제어는 가상 실행, 비교 화면도 시험 후보 제공 | 세션용 멈춤·V 시선·제어 해제·종료를 실제 실행 |
| 추가 행동 | 비교 화면에서 제스처 후보 3개 선택 표시. 실행 안 함 | 등록된 후보 목록에서 이동·제스처 등을 선택 결과로 표시. 실제 실행·성공 기록 없음 |
| 기억 | 원문/관찰 시험 기억·모의 슬롯 복원. 영구 저장/요약 없음 | 군중의 근거리 재접촉과 고유 인물의 게임 저장별 기억·로드 복원. 단기·장기 조회와 기본 로컬 정리는 [기억 규격](memory-specification.md) |
| 게임 진행 | 게임 미연결 | 채팅·요청 대기 중에도 게임 진행, 위험·원작 제어 발생 시 종료·복구 |

기존 대화 선택지 전환, 표시 복장 설명 수집, 게임 저장 경계와 정확한 저장 건 연결은 첫 게임판의 필수 지원 조건이다. 지원하지 못한 구현을 같은 완성 범위로 출시하지 않고 개발 상태와 제한을 표시한다. 지원 실행기가 없는 대상은 실제 제어 대상으로 활성화하지 않는다.

## 3. 콘텐츠 및 기억의 경계

원작 퀘스트·관계·보상은 AI 대화로 변경하지 않는다. 과거 대화는 기억하되 커뮤니티의 기본 태도·호칭·친밀도는 현재 원작 관계에서 계산한다. 누적 호감·불신으로 별도 관계를 성장시키지 않는다. 현재 상황의 감정 표현은 허용한다. 사소한 일상 창작의 대상·한계는 [콘텐츠 규격](content-specification.md#91-사소한-일상-창작-정책)을 따른다.

이전 옷 비교에는 같은 NPC가 실제로 관찰한 복장 기억이 필요하다. 원작 대사 전체를 대화 이력에 복사하지 않고 진행도에 맞는 승인된 사건 요약·인지·목표·관계 맥락을 제공한다.

## 4. 실행과 데이터

기본 구성은 게임 내부 모듈과 로컬 콘텐츠·설정·기억 저장소다. 별도 C# 프로그램이나 제작자 운영 서버는 필수가 아니다. 구체 계약은 [통신](runtime-specification.md), [NPC 식별](npc-identity-specification.md), [게임 정보](game-context-specification.md), [콘텐츠](content-specification.md), [행동](npc-action-scope.md)을 따른다.

## 5. 후속 확장 및 제외 범위

후속에는 대화에 맞는 제스처·표정·생활 동작·이동을 기존 게임 자산 및 기존 모드 연동으로 실행한다. 신규 모션 직접 제작은 요구하지 않는다. [행동 명세의 어댑터 계약](npc-action-scope.md#10-기존-게임모드-행동-연동)에 따라 선택 가능 여부·호환·취소·복구를 제공한다. 동행·차량·거래도 각각 지원 프로필을 갖춘 뒤 확장한다.

NPC 음성은 후속에 확정 대사 자막과 함께 재생한다. 현재 시제품과 첫 게임판은 대사 자막만 목표로 한다. 유료 기억 요약과 로컬 모델도 선택적 후속 기능이다. 플레이어 음성, 원작 퀘스트 대체·관계 변경, 군중 재생성 후 기억 승계, 즉석 모션 생성, 다중 NPC 자율 대화와 입력 없는 상시 AI 실행은 범위 밖이다.
