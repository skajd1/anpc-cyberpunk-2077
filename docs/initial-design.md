# ANPC 초기 버전 명세

규격 버전: 0.4 (2026-10-07). 단계별 범위. 구현/시험 상태: [개발·검증 계획](development-validation.md).

## 1. 지원 범위

단일 NPC·텍스트 입력·NPC 자막·일본어 NPC 음성. 자유 상태의 군중/지원 커뮤니티만. 커뮤니티는 승인 카드+게임 인물/진행/관계 매핑 필수. 군중 성격은 유효 인스턴스 고정, 커뮤니티는 오리지널 고정. 핵심 성격: [Big Five](personality-specification.md).

## 2. 단계별 포함 기능

| 구성 | 첫 게임판 규격 |
| --- | --- |
| 진입 | 커뮤니티는 기존 선택지 아래 추가 선택지, 군중은 짧은 기본 반응 후 추가 선택지. 절차는 [NPC 식별 규격](npc-identity-specification.md) |
| 입력·출력 | 채팅 입력·기록과 NPC 대사 자막, 대기·취소·종료·오류 UI. 자막 계약은 [통신 규격](runtime-specification.md) |
| 음성 | 주요 인물로 파인튜닝한 단일 TTS 모델과 인물·감정별 원작 참조 음성으로 만든 일본어 NPC 음성. 실패 시 자막만. [음성 출력 규격](npc-voice-output-specification.md) |
| 연결 | 개인 API 키와 비동기 요청·형식 검사·오류·취소 처리. 제작자 서버 없음 |
| 정체성·지식 | 승인된 인물·군중 데이터, 진행도별 오리지널 기억·지식·관계 맥락 |
| 복장 | 실제 표시 복장의 현재 아이템 이름·외형 텍스트. [게임 정보 규격](game-context-specification.md) |
| 평판 | 승인된 평판 임계 규칙에 따라 처음 만난 시민도 V의 이름·공개 행적 인지 가능 |
| 기본 제어 | 세션용 멈춤·V 시선·제어 해제·종료를 실제 실행 |
| 추가 행동 | 등록된 후보 목록에서 이동·제스처 등을 선택 결과로 표시. 실제 실행·성공 기록 없음 |
| 기억 | 군중의 근거리 재접촉과 고유 인물의 게임 저장별 기억·로드 복원. 현재 세션 발화·세션당 한 줄 요약은 [기억 규격](memory-specification.md) |
| 게임 진행 | 채팅·요청 대기 중에도 게임 진행, 위험·오리지널 제어 발생 시 종료·복구 |

첫 게임판 필수: 기존 선택지 전환·표시 복장 수집·정확한 저장 경계/연결. 미지원은 완료 범위로 출시하지 않는다. 지원 실행기 없는 실제 제어 비활성.

## 3. 콘텐츠 및 기억의 경계

오리지널 퀘스트/관계/보상 변경·누적 호감/불신 없음. 기본 태도/호칭은 현재 오리지널 기준, 순간 감정은 허용. 일상 범위는 [콘텐츠 규격](content-specification.md#91-사소한-일상-창작-정책).

복장 관찰을 별도 기억으로 의무 보존하지 않는다. 오리지널 맥락은 승인 단계 요약으로 제공하며 전체 대사를 기록에 복사하지 않는다.

## 4. 실행과 데이터

게임 내부 모듈+로컬 설정/콘텐츠/기억. 별도 C#/제작자 서버 필수 없음. 세부 계약: [전체 명세](full-specification.md).

첫 게임판 개발 단계(G0~G7)는 [개발·검증 계획](development-validation.md#3-개발-순서)에 둔다.

## 5. 후속 확장 및 제외 범위

후속: 지원 프로필을 갖춘 기존 자산/모드 제스처·표정·생활/이동·동행/차량/거래, 선택 유료 요약/로컬 모델. 신규 모션 제작 필수 없음. [행동 규격](npc-action-scope.md) 적용.

선택 후속: [플레이어 음성 인식](speech-recognition-specification.md). 확정 텍스트를 기존 입력 경로에 전달하며 첫 게임판의 텍스트 입력을 유지한다.

제외: 첫 게임판 플레이어 음성·오리지널 대체/관계 변경·재생성 군중 승계·즉석 모션·다중 NPC 자율 대화·입력 없는 상시 AI.
