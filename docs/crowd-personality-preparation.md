# 군중 NPC 랜덤 성향·배경 준비

2026-10-04, research-1.3. [작성 원형 9개](../content/cyberpunk2077/crowd-archetypes.json)와 [지식 묶음](../content/cyberpunk2077/crowd-knowledge-policy.json)을 작성했다. 전부 draft/runtime_enabled=false다. 슬롯·수준의 뜻과 모델 문구는 [Big Five 규격](personality-specification.md)이 기준이며 이 문서에서 별도 변환표를 만들지 않는다.

## 랜덤 슬롯

| 슬롯 | 추첨 후보 | 생활 대화에서 확인할 차이 |
| --- | --- | --- |
| openness | 1~5, 각각 weight=1 | 익숙한 방법을 유지할지 새 제안을 탐색할지 |
| conscientiousness | 1~5, 각각 weight=1 | 준비·순서·책임 확인과 당장 대응 중 무엇을 우선할지 |
| extraversion | 1~5, 각각 weight=1 | 여유 있는 상황에서 화제를 넓힐지 현재 화제에 머물지 |
| agreeableness | 1~5, 각각 weight=1 | 조정 가능한 갈등에서 자기 입장과 협력을 어떻게 저울질할지 |
| neuroticism | 1~5, 각각 weight=1 | 불확실성·비판에 대한 걱정·불쾌감과 침착함의 차이 |

모든 원형에 3,125개 조합을 열어 둔다. 조합의 가중치는 다섯 후보 weight의 곱이며 초기 설정에서는 같다. 정서 민감성 5와 우호성 1 같은 조합 자체는 모순으로 금지하지 않는다. 차분한 성격이 안전한 행동을 보장하지 않고, 민감한 성격이 폭력·질환을 부여하지 않는다. 표의 분포는 작성용 초기값이며 실제 인구 통계나 매 응답의 행동 확률이 아니다. 기존 웹 군중 두 카드의 분포·금지 조합을 변경하거나 이 원형에 자동 이식하지 않았다.

원형의 직업으로 축을 제한하지 않는다. 말 많은 의료 종사자, 조용한 판매원, 새 방법을 좋아하는 경비도 가능하다. 직업에 맞는 어휘·지식·정보 공개·업무 권한은 별도 승인 배경으로 제한하며 성격이 이를 해제하지 않는다. 강한 업무 압력 때문에 정해지는 반응은 성격 평가의 자유 선택 기회에서 제외한다.

## 원형과 검수 기본 조합

기본 조합은 추첨 실패 때 사용할 개별 작성 후보다. 승인 없이 실행하지 않으며 미설정 성격을 전부 3으로 채우는 기본값이 아니다. 다섯 숫자의 순서는 개방성·성실성·외향성·우호성·정서 민감성이다.

| 원형 | 필요한 배경 근거 | 기본 조합 | 직업·지역 필수 묶음 |
| --- | --- | --- | --- |
| 일반 시민 | 관찰된 직업이 없을 때 승인된 시민 배경만 사용 | 2 / 4 / 2 / 3 / 2 | 공통 기본 지식 |
| 배달·물류 종사자 | 배달·물류 업무가 확인된 승인 배경 | 4 / 3 / 4 / 2 / 3 | courier_worker |
| 정비 종사자 | 정비 업무와 담당 장비 종류가 확인된 승인 배경 | 5 / 4 / 2 / 3 / 2 | mechanic_worker |
| 기업 근로자 | 기업 관련 업무만 확인된 승인 배경. 특정 회사·직급은 별도 확인 | 2 / 4 / 3 / 2 / 4 | office_worker |
| 상점 종사자 | 상점 업무가 확인된 승인 배경. 품목·영업·재고는 별도 확인 | 3 / 3 / 4 / 4 / 2 | retail_worker |
| 의료·시술 종사자 | 의료 업무와 역할 범위가 확인된 승인 배경. 의료인 자격은 역할 관찰만으로 창작 금지 | 3 / 5 / 2 / 4 / 2 | medical_worker |
| 경비 종사자 | 경비 업무가 확인된 승인 배경. 경찰·군인·갱 소속은 별도 확인 | 2 / 5 / 2 / 2 / 3 | security_worker |
| 넷 업무 종사자 | 넷 관련 업무가 확인된 승인 배경. 회사·넷러너 등급·접속 이력은 별도 확인 | 5 / 4 / 2 / 3 / 4 | net_worker |
| 외곽 생활자 | 외곽 거주·생활 배경이 확인된 승인 배경. 노마드·알데칼도 소속은 별도 확인 | 4 / 3 / 3 / 4 / 2 | badlands |

외형·현재 위치만으로 역할·거주·갱·기업·국적을 부여하지 않는다. 특정 역할의 근거가 unknown이면 승인된 일반 시민 후보로 제한하고 시민 후보도 미승인이면 생성하지 않는다. 원형 선택 weight=1은 승인·관찰 필터를 통과한 후보끼리만 적용한다.

## 지식과 생활 소재

공통 기본은 world-knowledge-policy.json의 35개 사실을 참조한다. 지역 묶음은 확인된 거주·지속 활동에 맞춰 필수 배분하며 현재 좌표만으로 부여하지 않는다. 직업 묶음은 업무 역할 근거를 확인한 뒤 개별 인지·깊이·공개를 통과한 최소 개요로 쓴다. 선택 관심은 승인된 eligible 후보에서 최대 2개이며 사실의 참·거짓, 비밀, 직접 경험을 추첨하지 않는다. 군중의 지식 소유·인지 변환은 아직 미구현이므로 knowledge_ids를 비워 두고 release_blockers에 기록했다.

| 역할 | 대화에서 구별할 한계 | 허용 생활 소재 후보 |
| --- | --- | --- |
| 일반 시민 | 현재 화제에 맞는 의견과 모르는 범위를 구분한다. | 현재 대화에 대한 감상 / 먹거리·음악에 대한 가벼운 취향 |
| 배달·물류 종사자 | 지금 상대가 원하는 정보와 실제 배송 요청을 구별한다. | 작업 준비의 번거로움 / 업무 중 느끼는 일반적인 피로 |
| 정비 종사자 | 대상이 확인됐는지부터 나누고 미등록 절차와 수리 성공은 약속하지 않는다. | 작업 정리의 번거로움 / 장비를 다루는 취향 |
| 기업 근로자 | 공개 기업 정보와 회사 내부 정보·접근권을 분리한다. | 업무 일정의 부담 / 휴식에 대한 가벼운 바람 |
| 상점 종사자 | 질문과 거래 요청을 나누고 관찰 없는 상품·가격은 확정하지 않는다. | 일을 정리하는 번거로움 / 먹거리 취향 |
| 의료·시술 종사자 | 제공된 서비스 개요와 실제 진료·진단을 구별한다. | 업무 중 일반적인 피로 / 정돈·휴식에 대한 감상 |
| 경비 종사자 | 경비 역할과 경찰 권한·실제 출입 승인·체포를 구별한다. | 업무 중 피로 / 쉬는 시간에 대한 가벼운 감상 |
| 넷 업무 종사자 | 공개 넷 개요와 특정 시스템의 내부 정보·직접 접속을 구별한다. | 일반적인 작업 피로 / 화면 작업·휴식에 대한 감상 |
| 외곽 생활자 | 확인된 지역 개요와 자기 경험·클랜 관계를 구별한다. | 생활을 정리하는 번거로움 / 먹거리·이동에 대한 취향 |

일상 소재는 현재 활동·단계와 승인 정책을 통과한 사소한 자기보고만 허용한다. 오늘의 배송·범죄·시술·날씨·매출을 실제 관찰로 만들거나 새 가족·유명인 친분·전문 교육으로 확대하지 않는다. 말투 지침은 역할 어휘와 대화 범위이며 외향성·우호성의 대체 슬롯이 아니다.

## 재현과 재접촉

동일 인스턴스·원형 revision·콘텐츠 버전에서 personality와 knowledge 하위 seed를 따로 파생한다. 실제 seed 파생·인스턴스 저장 구현은 후속 작업이다. 기존 generateCrowdPersonality로 후보 프로필의 수준 범위·동일 seed 재현을 오프라인 검사했다. 이 검사가 게임의 재접촉·저장/로드·배경 관찰까지 검증한 것은 아니다.

유효 대화와 근거리 재접촉에는 생성 레코드의 다섯 수준·배경·지식 선택을 재사용한다. 턴·칭찬·모욕·장비 변경으로 다시 뽑지 않으며 기억으로 관계·기본 태도를 누적 변경하지 않는다. 만료·대상 소멸·다른 저장 계보의 취급은 NPC 식별·기억 명세를 따른다.

## 승인 전 남은 작업

원형별 관찰 근거와 실제 게임 매핑, 기본 조합·판단·문체의 사람 검수, 분야 상한·인지 소유 변환, 군중 대사 예시, 한 인스턴스의 재접촉·저장/로드를 검증해야 한다. 세 슬롯 temperament/core_value/social_attitude는 호환 자료로만 남기고 새 다섯 슬롯과 함께 추첨·주입하지 않는다.
