# NPC 음성 모델 파인튜닝 작업 절차

ANPC 음성 모델(GPT-SoVITS v2ProPlus 다화자 파인튜닝)을 사내 GPU 서버(RTX 5080)에서 학습하고 배포용 ONNX로 만드는 절차다. 모델·학습 자료의 조건은 [음성 출력 규격 3.1](npc-voice-output-specification.md#31-음성-모델과-학습-자료)이 기준이다.

## 1. 지킬 것

- 원작 음성·대본·특징 파일·체크포인트는 저장소 밖 작업 폴더에만 둔다. 저장소와 배포 패키지에는 ONNX 모델과 학습 목록 메타데이터만 넣는다.
- 서버 주소·계정·키는 이 문서에 적지 않는다. 접속 정보는 각자의 SSH 설정에 둔다.
- 게임 원작 음성을 사내 서버로 옮기기 전에 사내 규정상 허용되는지 확인한다.
- V의 대사와 군중 대사는 학습하지 않는다.

## 2. 준비물

| 항목 | 기준 |
| --- | --- |
| 서버 | RTX 5080, 키 인증 SSH, 디스크 여유 15~20GB(최소 10~12GB), 인터넷 연결 |
| GPU 시간 | 본 학습 동안(4절) 다른 작업과 겹치지 않게 조율. GPU 메모리 여유가 8GB 안팎이면 SoVITS 배치 4·GPT 배치 6 |
| 소프트웨어 | PyTorch·torchaudio 2.8(cu128)과 이를 지원하는 NVIDIA 드라이버. RTX 5080은 이전 CUDA 빌드로는 동작하지 않는다. torchaudio 2.9 이상은 torchcodec이 필요해 전처리가 실패한다. 서버에 ffmpeg가 없으면 imageio-ffmpeg의 실행 파일을 PATH에 둔다 |
| GPT-SoVITS | 커밋 `48b1a016`(로컬 실측과 Genie 변환에 쓴 버전)과 v2ProPlus 사전학습 가중치 |
| 게임 PC | 일본어 음성이 설치된 사이버펑크 2077. 음성 추출은 이 PC에서 한다 |
| 학습 대상 | 주요 인물 목록. 인물마다 voice_profile_id를 정해 둔다 |

장시간 작업은 서버에서 `tmux` 같은 세션 유지 도구 안에서 실행해 SSH가 끊겨도 계속되게 한다. WebUI를 쓰면 SSH 포트 전달로 내 PC 브라우저에서 연다.

## 3. 절차

| 단계 | 작업 | 끝났다는 기준 |
| --- | --- | --- |
| 1. 환경 | 작업 폴더에 Python 3.10 가상 환경을 만들고 PyTorch·torchaudio 2.8(cu128) 설치 → GPT-SoVITS 받아 `48b1a016`으로 고정 → 의존성·사전학습 가중치(s2Dv2ProPlus 포함) 설치. 학습 스크립트 실행 시 PYTHONPATH에 저장소 루트와 `GPT_SoVITS`를 둔다 | `torch.cuda.is_available()`이 참이고 장치 이름이 RTX 5080 |
| 2. 추출 | 게임 PC에서 대상 인물의 일본어 음성 대사를 WAV로 추출하고, 같은 string_id의 일본어 자막을 대본으로 붙인다. 결과를 서버 작업 폴더로 옮긴다 | 인물별 파일 수·총 길이 표 |
| 3. 정제 | 홀로콜(통화 필터)·무전·효과음/배경음악이 섞인 대사, 다른 화자와 겹친 대사, 비명·숨소리·전투 외침을 뺀다. 1.5초 미만은 빼고 15초 초과는 자르거나 뺀다. 대본의 서식 태그·루비를 지운다 | 인물마다 무작위 10줄 청취에서 문제 없음 |
| 4. 학습 목록 | `wav경로\|화자명\|ja\|대본` 형식 목록을 만든다. 화자명은 voice_profile_id. 화자별 분량 상한 10~20분. 인물마다 평가용 대사 5~10줄을 학습에서 뺀다 | 화자별 분량이 상한 이하, 평가용 목록 따로 있음 |
| 5. 시범 실행 | 인물 2명·1 epoch로 전처리부터 SoVITS·GPT 학습까지 한 번 돌린다 | 오류 없이 체크포인트 생성 |
| 6. 본 학습 | 전처리(대본 음소·BERT, HuBERT, 화자 특징, 의미 토큰) → SoVITS 8~10 epoch → GPT 10~15 epoch. fp16, 2~3 epoch마다 저장 | 학습 손실 기록과 체크포인트 |
| 7. 비교 | 체크포인트별로 평가용 대사·처음 보는 문장·학습에 없던 군중 참조 음성을 합성해 청취 비교. 원본과의 1/3옥타브 음색 차이도 함께 본다 | 억양이 뭉개지거나 다른 인물 음색이 섞이지 않는 체크포인트 하나 선택 |
| 8. 변환 | 고른 SoVITS·GPT 체크포인트를 Genie ONNX로 변환(fp16 체크포인트는 변환기가 fp32로 바꿈) → GPT 디코더 두 개를 fp32 단독 파일로 만들어 ONNX Runtime 기본 최적화로 상수 접기 → 가중치 int8 동적 양자화(MatMul·Gemm, 채널별). VITS는 fp32로 둔다 | 변환본 소리가 체크포인트와 같고, int8과 fp32 청취 차이 없음 |
| 9. CPU 검증 | 기준 PC(Ryzen 5 7500F)에서 Genie 4스레드로 실시간 대비 처리 속도(RTF), 첫 음성 지연, 메모리, 끝 음절 잘림을 게임 끔·게임 중으로 잰다 | 게임 끔 fp32 RTF가 기본 모델 실측(0.66~0.76)과 비슷하고, 게임 중 int8 RTF가 [실측](development-validation.md#82-npc-음성-파인튜닝-v1게임-중-실측-2026-10-0708)(1.1 안팎)보다 나쁘지 않음 |
| 10. 기록 | voice_model_version을 정하고 ONNX와 학습 목록 메타데이터를 보관. 결과 수치를 5절에 적는다 | 학습 오디오·대본·체크포인트가 저장소·패키지에 없음 |

학습 목록 메타데이터 항목: voice_model_version, 기반 커밋·가중치 버전, 화자별 voice_profile_id·string_id 목록·분량, 화자별 상한, 선택한 epoch.

인물을 추가할 때는 2~10단계를 반복하고 기존 인물을 포함한 전체 자료로 다시 학습한다. 새 버전은 voice_model_version을 올린다.

## 4. 소요 시간

v1 실측(인물 3명·화자별 20분·총 870줄, SoVITS 배치 4·GPT 배치 6, 다른 서비스가 GPU 메모리 약 8GB 점유).

| 구간 | 시간 |
| --- | --- |
| 첫 환경 구성(다운로드 포함) | 30~60분 (추정) |
| 시범 실행(인물 2명·60줄·1 epoch) | 약 1분 |
| 전처리 | 1.2분 |
| SoVITS 학습 10 epoch | 8.2분 |
| GPT 학습 15 epoch | 1.4분 |
| 본 학습 합계 | 약 11분 |

자료 분량과 epoch 수에 거의 비례한다. 주요 인물 10명·화자별 20분이면 본 학습은 약 40분으로 추정한다.
