# 모드 패키지·설치·백업·복원 규격

규격 버전: 1.0 (2026-10-05). [플레이어 기능 명세](gameplay-functional-specification.md)의 UF-01/02/54/55/60/61에 적용한다. 구현 상태/출시 공백은 [명세 대조 리뷰](game-mod-spec-review-2026-10-05.md), 실제 배포 기록은 [배포 변경 이력](game-mod-validation.md)에 둔다.

## 1. 배포 범위와 소유권

| ID | 규칙 |
| --- | --- |
| DIST-01 | 개발 시험 패키지와 공개 배포를 구분한다. 개발 ZIP 생성은 기능·콘텐츠·호환성 출시 승인이 아니다. |
| DIST-02 | ZIP은 게임 루트 기준 상대 경로의 ANPC 소유 파일, 패키지 목록/해시, 설치/제거 안내와 라이선스 고지만 포함한다. |
| DIST-03 | 게임 실행 파일·원본 archive/final.redscripts·세이브·캐시·.env·개인 경로/설정·로그·키·백업·개발 서버/테스트·조사 원문을 포함하지 않는다. |
| DIST-04 | RED4ext/redscript/CET/Codeware는 별도 필수 의존성이다. 제작자 승인 없이 코어 도구를 ANPC ZIP에 묶거나 설치/제거하지 않는다. |
| DIST-05 | 매 빌드에서 최신 생성 프롬프트 일치, 파일 SHA-256, 포함/제외 목록, 패키지 버전·지원 프로필·의존성·콘텐츠 승인 상태를 검사한다. |
| DIST-06 | 공개 채널은 미검수 콘텐츠/필수 기능·실게임 지원 검사·라이선스가 미완이면 빌드를 거부한다. 개발 초안 예외를 공개판에 승계하지 않는다. |

게임 설치 대응은 다음 세 ANPC 디렉터리다. 새 자산은 실제 사용/필요성이 검증된 경우에만 소유 목록에 추가한다. 현재 사용하지 않는 장면 interaction 연구 자산을 자동 포함하지 않는다.

| 구성 | 설치 상대 경로 |
| --- | --- |
| CET Lua·생성 콘텐츠·키 없는 기본 설정 | bin/x64/plugins/cyber_engine_tweaks/mods/anpc/ |
| redscript | r6/scripts/ANPC/ |
| 제품 Native 플러그인 | red4ext/plugins/ANPC/ANPC.Native.dll |

Node.js·WolvenKit·빌드 도구는 제작/개발 의존성이다. 제품 Native 대화의 플레이어 실행 필수 의존성으로 요구하지 않는다. 개발 파일 브리지는 공개 패키지의 기본 대화 경로가 아니다.

## 2. 최초 설치와 업데이트

| ID | 상황 | 필수 처리 |
| --- | --- | --- |
| DIST-07 | 설치 시작 | 게임 루트/패치/필수 도구·게임 종료·경로 경계·파일 목록/해시·디스크 쓰기 가능 여부를 변경 전에 확인한다. |
| DIST-08 | 새 설치의 동일 경로에 기존 파일 존재 | 이전 ANPC 소유/상태를 확인하지 못하면 충돌로 중단한다. ‘ANPC 이름의 폴더’만으로 삭제/덮어쓰기 권한을 추정하지 않는다. |
| DIST-09 | 확인된 ANPC 업데이트 | 기존 설치 목록과 실제 해시를 비교한다. 기본 설정과 사용자 설정을 분리하고 사용자 설정을 보존한다. 누락/추가된 소유 파일도 기록한다. |
| DIST-10 | 파일 변경 전 | 기존 파일과 설치 목록을 게임 밖의 영구 백업에 복사하고 해시를 확인한다. 새 파일은 기존 파일 없음으로 기록한다. 임시 폴더만을 유일한 복구본으로 사용하지 않는다. |
| DIST-11 | 설치 도중 실패 | 변경 목록을 기준으로 이번 작업을 되돌리고 성공한 단계/미복구 항목을 명시한다. 부분 설치를 성공으로 표시하지 않는다. |
| DIST-12 | 설치 완료 | 설치 파일 해시 재검사·설치 이력 보관·재시작 안내. 파일 복사 성공과 실제 게임 컴파일/대화 성공을 구분한다. |

백업/설치 이력에는 패키지 버전·작업 시각·대상 상대 경로·변경 전/후 SHA-256·이전 파일 유무·백업 상대 경로·작업 결과를 남긴다. 백업은 개인 로컬 자료이며 Git/배포 ZIP에 포함하지 않는다. 게임 세이브 백업은 별도 기능이며 모드 파일 백업 성공으로 세이브까지 백업했다고 표시하지 않는다.

## 3. 되돌리기·제거·설정과 키

| ID | 상황 | 필수 처리 |
| --- | --- | --- |
| DIST-13 | 되돌리기 | 게임 종료 후 선택한 설치 이력·백업 해시·현재 설치 해시를 검사한다. 변경 전 있던 파일은 복원, 없던 파일은 이번 설치가 만든 해시와 일치할 때만 제거한다. |
| DIST-14 | 사용자가 파일 수정/다른 모드가 덮어씀 | 해당 파일은 자동 복원/삭제하지 않고 충돌 목록을 제공한다. 전체 재귀 삭제나 무조건 덮어쓰기 금지. |
| DIST-15 | ANPC 제거 | 설치 소유 목록의 검증된 파일만 제거/원복한다. 다른 모드·코어 도구·오리지널·세이브·키·설정을 기본 보존한다. |
| DIST-16 | 키/기억/사용량 초기화 | 제거와 분리된 사용자 명시 동작으로 처리한다. 오리지널 진행·세이브를 변경하지 않는다. |
| DIST-17 | 백업 없음/해시 불일치 | 복원 불가 이유와 안전하게 가능한 작업을 알린다. 다른 버전 파일을 원본으로 추정하거나 빈 파일을 대신 만들지 않는다. |

파일을 복원해도 과거 게임 진행이나 이미 청구된 API 사용을 되돌리지 않는다. 사용자가 저장한 키는 Windows 자격 증명 관리자에 있으며 ZIP/설치 이력으로 복사하지 않는다.

## 4. 패키지 수용과 공개 배포

| ID | 검사 | 통과 기준 |
| --- | --- | --- |
| DIST-18 | 깨끗한 시험 설치 | 지원 게임/도구에서 목록과 실제 파일 동일, Node 서버 없이 Native 대화 가능 |
| DIST-19 | 버전 업데이트/충돌 | 사용자 설정·다른 모드 보존, 변경 파일/해시 정확, 충돌 시 변경 전 중단 |
| DIST-20 | 중간 실패/복원/제거 | 장애를 넣은 검사에서 변경 전 상태 복원. 새 파일 제거와 이전 파일 복원을 각각 확인 |
| DIST-21 | 보안/저작물 포함 범위 | 키·개인 파일·게임 원본·조사 원문/코어 도구 제외. 자체 소스와 동봉 라이브러리의 라이선스/고지 검토 완료 |
| DIST-22 | 실제 게임 회귀 | 시작/종료·기존 저장·진입/대화/중단·실행 가능한 행동·설치/제거 실증 완료. 모의 검사나 CLI 컴파일만으로 통과 처리하지 않음 |

출시 버전은 지원 NPC·허용 진행 구간·모델·콘텐츠·행동·플랫폼/패치/의존성 조합을 명시한다. 미지원 인물을 자료 개수만으로 지원 목록에 넣지 않는다. 출시 차단 항목은 개발 ZIP 생성으로 해제하지 않는다.
