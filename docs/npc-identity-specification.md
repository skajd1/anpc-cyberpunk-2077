# NPC 식별 및 대화 허용 규격

규격 버전: 0.4 (2026-10-01). 모든 키는 ANPC의 논리 키이며 게임이 동일한 필드를 제공한다는 의미가 아니다.

## 1. 식별 구조

| 필드 | 정의 | 사용 |
| --- | --- | --- |
| save_scope | 현재 저장 계보를 구분하는 키 | 다른 플레이 기록과 기억 분리 |
| world_epoch | 로드·빠른 이동·세계 전환마다 갱신되는 세대 | 이전 객체·응답 무효화 |
| instance_token | 살아 있는 객체의 참조와 생성 세대를 묶은 키 | 현재 NPC 구분 |
| npc_instance_key | 위 세 필드의 조합 | 세션·임시 기억·행동 대상 |
| character_key | 수작업 매핑한 고유 인물 키 또는 null | 커뮤니티 카드·저장 연동 기억 |
| record_id | 게임 레코드 ID 또는 null | 유형·프로필 조회 보조 |
| npc_type | crowd, community, unsupported | 콘텐츠 정책 선택 |

이름·외형·위치·record_id만으로 동일 인물을 판정하지 않는다. 군중은 npc_instance_key로만 기억을 이어간다. 커뮤니티도 character_key 매핑이 없으면 인스턴스 범위만 지원한다. 기존 인물에 카드가 없으면 community_profile_missing으로 대화를 거부한다. 군중 생성 카드를 기존 인물에게 대신 적용하지 않는다.

## 2. 대화 허용 판정

다음 조건을 모두 만족하면 시작을 허용한다.

- 유효하고 살아 있는 NPC이며 군중·커뮤니티 유형이 확정된다.
- 상호작용으로 선택한 단일 대상이고 AI 대화 시작 거리는 4m 이하다. 군중은 조준·상호작용으로 선택하고 커뮤니티는 원작 대화 대상과 연결한다. 주변 인물을 자동 선택하지 않는다.
- 현재 세션이 없고 설정된 모델·키와 해당 NPC의 콘텐츠가 준비되어 있다.
- 플레이어와 대상이 전투·원작 대화·시네마틱·퀘스트 강제 제어·운전 상태에 있지 않다.
- 대상이 차량이나 기존 워크스팟에 묶여 있지 않다. 후속 지원 프로필이 명시적으로 허용한 경우만 예외다.
- 커뮤니티 프로필의 대화 가능 조건과 현재 퀘스트 단계가 일치한다.

거리 기본값은 설계 정책이며 설정으로 조정할 수 있다. 안전 상태 중 필수 값이 unknown이면 시작을 거부한다. 시작 후 동일 조건을 계속 감시하며 거리 10m 초과는 세션 종료 사유다. 이동 중 동행도 이 종료 거리 안에서만 지속한다.

판정 결과는 eligible, reason_code, npc_instance_key, character_key, profile_id를 반환한다. 거부 사유는 invalid_target, unsupported_type, too_far, busy, combat, quest_controlled, mounted, workspot_busy, state_unknown, community_profile_missing, model_unavailable 중 하나다.

### 2.1. AI 대화 진입과 원작 제어 전환

진입 선택지의 기본 표시 문구는 “더 깊은 대화를 해볼까?”다. 커뮤니티에서는 지원 인물의 기존 선택지 아래에 비파괴적으로 추가한다. 기존 선택지의 문구·순서·결과·관계/퀘스트 효과는 유지한다. 추가 선택지 자체는 퀘스트·관계 플래그를 변경하지 않는다. 강제 장면을 중간에 끊거나 선택 가능하지 않은 원작 시점에 삽입하지 않는다.

군중은 조준·상호작용에 대한 짧은 기본 반응을 먼저 보인 뒤 추가 선택지를 제공한다. 기본 반응은 원작 반응 또는 승인된 로컬 기본문이며 모델을 호출하지 않는다. 원작 기본 반응을 바꿔야 하는 대상은 지원 프로필에서 별도 확인한다. 기본 반응만 보았다는 이유로 AI 세션·호감 변화·복장 기억을 생성하지 않는다.

진입 토큰은 대상 키·world_epoch·entry_source(community_option/crowd_option)·발급 시점에 연결하며 한 번만 소비한다. 선택지를 표시하는 동안 원작 대화는 유지할 수 있으나 AI 요청·정지·시선 제어는 아직 시작하지 않는다. 선택 후 지원 어댑터가 원작 대화의 안전한 종료·제어 반환을 확인하고 2절의 모든 조건을 재판정한 뒤 active로 전환한다. 원작 대화와 AI 대화를 동시에 제어하지 않는다.

제어 반환이 불가능하거나 필수 상태를 확인하지 못하면 진입하지 않는다. 사용자가 취소하거나 대상/세계가 바뀌면 토큰·선택지를 폐기한다. 재접촉도 같은 진입 흐름과 판정을 사용하며 반경만으로 자동 발화하지 않는다. 종료 후 원작 상호작용으로 돌아갈 수 있도록 ANPC 제어·UI만 정리한다. 선택지를 제공하지 못하는 프로필을 자동으로 조준 즉시 채팅 방식으로 바꾸지 않는다.

## 3. 재접촉과 기억

커뮤니티 카드의 정체성과 군중의 원형·특성 조합은 [콘텐츠 규격](content-specification.md)의 확정된 구조를 따른다. 여기서 보관·무효화하는 군중 생성 데이터에는 정체성·판단 규칙·말투와 콘텐츠·생성기 버전이 포함된다. 재접촉 시 대화 기억과 해당 생성 데이터를 함께 복구한다.

정상 종료한 최근 NPC 최대 16명에 한해 생성 특성, 이름 인지, 대화·복장 관찰 기억·약속을 메모리에 보관한다. 재접촉은 같은 살아 있는 인스턴스, 종료 후 10분 이내, 거리 10m 이내일 때 가능하다. 실제 대화 시작은 4m 조건을 따르며 10m 범위만으로 자동 발화하지 않는다. 시간은 실행 중 경과 시간을 사용한다.

거리 이탈만으로 기억을 삭제하지 않는다. 소멸·언로드·빠른 이동·저장 로드·save_scope 변경·만료·사용자 삭제 시 휘발 임시 기억을 폐기한다. 용량 초과는 가장 오래 사용하지 않은 항목부터 제거한다. 기억은 제어 명령을 포함하지 않는다. 저장 연동을 활성화한 커뮤니티의 작업 기억·저장 묶음은 [기억 규격](memory-specification.md#31-게임-저장과-기억-묶음의-연결)에 따라 유지·복원하며 이 임시 재접촉 한도를 영구 묶음 삭제 조건으로 적용하지 않는다.

저장 계보를 안정적으로 판정할 수 없으면 새로운 save_scope를 발급하고 이전 영구 기억을 연결하지 않는다. 저장을 넘어 유지하는 기억은 첫 게임판 목표이며 안정적인 character_key와 정확한 저장 대응이 모두 확인된 커뮤니티만 허용한다. 원작 관계·호칭·기본 태도는 현재 원작 상태에서 다시 계산하며 기억에서 누적 관계를 복원하지 않는다. 군중의 소멸 후 기억 승계는 범위 밖이다.

단기·장기는 기억 접근 영역, 휘발·영구는 보존 방식이다. 군중도 유효한 인스턴스 범위 안에서는 과거 대화의 요약 영역을 사용할 수 있다. 영역별 데이터·요약·조회·비동기 작업·저장 로드 시점 검사는 [NPC 기억 규격](memory-specification.md)에 둔다. 재접촉 시간·거리·인원 한도는 이 문서가 기준이다.
