# NPC 세계관 지식 부여 및 프롬프트 주입 규격

규격 버전: 1.2 (2026-10-03). 타입/포트: [공통 규격](module-interface-specification.md).

## 1. 저장 위치와 구분

content/cyberpunk2077/: world-facts.json=원작 사실, knowledge.json=인지/공개 조건, characters/*.json=정체성, dialogue-examples.json=예시, sources.json=출처, manifest.json=버전/상태/목록.

사실은 ID 참조, 인물별 복제 금지. 플레이어 신원은 [고정 신원](content-specification.md#플레이어-고정-신원), NPC 이름 인지는 별도 조건. source_checked≠approved. draft는 런타임 제외. 개발용 예외: [시제품 안내](dialogue-prototype.md#인물-설정과-대화-테스트).

## 2. 지식의 층

| knowledge_layer | 의미 | 군중 배분 | 커뮤니티 배분 |
| --- | --- | --- | --- |
| common | 통화·임플란트·도시 서비스 등의 상식 | 승인된 기본 목록. 인지 예외 프로필에서는 제외 | 작성된 기본 지식 목록 |
| regional | 동네·시설·지역 집단에 대한 생활 지식 | 승인된 거주·활동 배경 조건으로 부여 | 인물의 생활·활동 근거로 작성 |
| profession | 기술·의료·경비 등 전문 지식 | 승인된 업무 배경의 필수 지식과 선택 후보 | 원작의 전문 분야를 근거로 작성 |
| optional | 음악·위험 집단 등의 선택 관심 지식 | 인지 가능한 후보 중 제한 추첨 | 필요하면 카드에 명시적으로 작성 |
| personal | 개인 배경·관계·사적 경험 | 임의 배분 금지. 생성 배경은 창작으로 별도 보관 | 해당 인물·관계·공개 조건에 따라 제공 |
| quest | 사건 진행·비밀·렐릭·분기 결과 | 추첨 금지. 실제 인지 근거가 있는 별도 프로필만 허용 | 인물별 인지·진행·공개 조건으로 제공 |

공개 유명 인물: common/public_figures, 깊이 familiar. 이름·직업·명성만 공유하며 직접 친분·사적 경험·비밀·현재 생존/위치·퀘스트 결과는 별도 인지 조건. 공개 명성의 출처와 개별 NPC의 실제 인지 검수는 구별한다.

성격과 지식량 독립. 현재 위치만으로 주민/소속/전문가 추정 금지. 미관찰 직업/거주로 전문 지식 부여 금지.

## 3. 군중 배분 순서

1. 승인 원형/배경에서 고정 프로필. 조건에 맞는 공통/지역/직업 필수 지식 부여.
2. 시대·승인·인지 선필터. personal/quest 추첨 제외.
3. 선택 지식 최대 2개. 후보 부족 시 가능한 수만. 필수 지식 무작위 제거 금지. 정체성 seed의 knowledge 하위 seed로 분리.
4. knowledge_id/certainty/프로필 버전 저장. 유효 대화/재접촉 동안 재추첨 금지.
5. 플레이어 설명은 player_claim. 인지 갱신은 노출된 확인 게임/승인 이벤트만 사용.

추첨 대상은 보유 사실 ID뿐. 내용·진실·발생·경험 추첨 금지. 소문은 별도 출처+suspects로 작성. 후보 데이터: [지식 배분](../content/cyberpunk2077/crowd-knowledge-policy.json).

## 4. 커뮤니티 배분

- 카드 knowledge_ids 기준. 핵심 지식/깊이 무작위 변경 금지. 승인 분야 상한·사실별 인지·공개 조건 모두 검사.
- common도 인물별 근거 필요. 출신/직업 연상으로 개별 사실/실무 경험/교육/자격 추가 금지. awareness는 이름만, unknown은 근거 부족이며 실제 무지 확정 아님.
- 인지 갱신은 개인 노출 장면/이벤트+단계 근거. 플레이어 설명/일상 창작은 분야/경력 승격 근거 아님.
- 콘텐츠 개정은 버전 관리. 유효 세션 중 몰래 교체 금지.
- 공개 자료의 비밀도 NPC 인지/공개와 분리. 렐릭/V 상태는 인지+V 공개 조건 모두 필요. 모르는 실제 비밀은 생성 입력 제외.
- 현재 생존·소속·위치·관계·대화 가능 여부는 게임 상태. 사망 뒤 대화 및 웹 소개로 현재 상태 고정 금지.

## 5. 현재 묶음의 논리 조건 필드

정확한 타입·공개·조건은 [상태 필드 등록표](../contracts/v1/cyberpunk2077-fields.json)를 참조한다. content.grants.<fact_id>는 설명용 표기이며 각 사실 ID를 개별 등록한다. 실제 매핑 전 unknown. 플레이어 주장/표시 이름으로 확정 금지.

| 필드 | 형식 | 승인 값의 의미 |
| --- | --- | --- |
| content.era | 문자열 | 해당 자료의 시대. 현재 묶음은 2077 |
| content.npc_key | 문자열 | 승인된 실제 인물 매핑 |
| content.npc_alive_confirmed | 불리언 | 현재 게임에서 살아 있고 대화 가능한 존재로 확인 |
| content.npc_free_confirmed | 불리언 | 원작 대화·시네마틱·전투·퀘스트 제어 등 대화 금지 상태가 아님 |
| content.relationship_confirmed | 불리언 | 원작의 관계 단계와 호칭 정책을 판정 가능 |
| content.phase | 문자열 | 카드의 phase_labels 중 매핑·검수된 현재 단계 |
| content.grants.<fact_id> | 불리언 | 해당 인물의 승인 인지 조건을 현재 단계에서 충족 |
| content.player_disclosure.relic | 불리언 | V의 상태를 이 인물에게 공개할 조건이 충족됨 |

phase_labels는 의미 단계이며 원작 퀘스트 ID 아님. 필드값만으로 draft 활성화 금지.

## 6. 매 턴 프롬프트 주입

승인 → 인지/단계/공개 → 보유 ID → 분야 상한 → 관련 화제 → 최소 진술/확실성/해석/주장 한도.

공통 핵심은 허용된 모든 카테고리를 매 요청 주입. 세부·개인 지식은 요청 관련 항목만 전송. 전체 백과/출처/타 NPC 비밀 제외. 해석으로 사실 추가 금지. withheld는 회피 제한만 제공.

작성 사실의 선택 필드 entity_aliases: 중복 없는 비어 있지 않은 인명 문자열 목록. 로컬 검색 전용이며 KnowledgeView/ModelInput에 전송하지 않는다. 현재 인명 일치는 일반 화제보다 우선하며 비공개 조건을 해제하지 않는다.

### 6.1. 원작 기억·공개 유명세·대화 기억의 구분

원작 사건=CanonView, ANPC 경험=MemoryView. 원작 대사를 recent_turns로 복사하지 않는다. 매 요청 단계·분기·인지·관계·공개 필터.

공개 인지는 [평판 정책](content-specification.md#53-관계-기준과-공개-평판-반응). 비밀 권한 확대 없음. 관찰/일상 자기보고는 [기억 규격](memory-specification.md#43-복장-관찰과-생성-일상-기억).

## 7. 자료 확장 기준

출처·시대·스포일러·인지 대상·주장 한도 필수. 다른 시대 제도/가격/기술을 2077 현재로 복사 금지. 광고/회고는 주장·신뢰도·시점 구분. 충돌은 보류하며 모델 임의 선택 금지. 조사/구현 상태: [개발·검증 계획](development-validation.md).

## 8. 공통 세계관 지식과 인물별 인지

| 구성 | 장점 | 한계 | 채택 |
| --- | --- | --- | --- |
| 인물 카드에 사실 본문 복제 | 개별 검수·차별화가 단순 | 사실 수정 시 카드마다 갱신·내용 불일치 | 미채택 |
| 중앙 자료 + 공통 인지 규칙 | 사실 수정·확장이 한 곳에서 가능 | 공개 상식과 개인 경험의 경계를 세밀하게 지정해야 함 | 공통 상식에 사용 |
| 중앙 자료 + 인물별 허용 ID·깊이·조건 | 중복 없이 개인 경험·비밀·전문성 구분 | 인물별 배분 자료 검수가 필요 | 세부·개인 지식에 사용 |

- 범주: 인물, 기업, 직업, 나이트 시티, 역사, 사회·문화, 기술·사이버웨어, 갱·노마드, 치안·법집행, 경제·생활, 교통.
- 저장: world-facts의 category_id·injection_mode(baseline/selected). 정책은 world-knowledge-policy. 사실 본문은 중앙 자료에 한 번만 저장.
- baseline: 승인·인지·공개·시대·단계·개요 깊이 조건 통과 → CommonKnowledgeView. 화제와 무관하게 일괄 제공.
- selected: 같은 조건 통과 → 현재 입력·직전 화제의 관련 항목 → KnowledgeView.items. 현재 웹 최대 3개.
- 개인 경험·비밀·전문 지식은 knowledge_ids·분야 상한·접근 조건으로 명시 할당. 모델에 비밀 원문을 전달한 뒤 숨기라고 지시하는 방식 금지.
- 공통 상식은 개요 인지이며 실무/전문 깊이를 높이지 않는다. 거주·직업·원작 경험의 예외를 프로필에서 제외 가능.
- 중복: baseline에 들어간 사실은 selected에서 제외. 출처·별칭·조회 조건·전체 배분표는 모델에 보내지 않는다.
- 현재 웹: 공통 핵심 직렬화 최대 3000자. 초과는 context_unavailable. 실제 토큰 총예산 적용은 비용 규격 참조.
- 조니 각성 초기의 2077 시대 정보는 common_exclusions_by_stage로 제한. 렐릭·개인 관계를 공개 상식으로 승격 금지.
