# ANPC

ANPC (Autonomous Non-Player Character) is a planned Cyberpunk 2077 mod for text conversations and context-aware NPC behavior. Street crowd NPCs receive generated personas; existing community NPCs retain their established characterization.

This repository currently contains specifications. No playable mod has been implemented or verified in-game.
